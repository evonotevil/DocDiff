# DocDiff 1.6.0

这一版的主题是“交得出去”：比较结果能直接交给律师、领导或对方，每个判断都署上名字。内容来自三位专家的交叉评审和审阅人方案，更新地址仍由发版人手动处理。

## 审阅人与审阅记录

- **审阅人**：设置 → 审阅里填姓名和缩写，默认取电脑的登录名。第一次进入修订审阅时会在底部提示一次。
- **三种结论**：接受（A）、拒绝（R），以及新增的**待议**（H），用来标记要交给律师或领导判断的条款。每个决定可以附一句备注（按 N 直接输入）。
- **决定会保存**：按两份文件的 SHA-256 存在本机，关掉应用再打开、改比较设置都不会丢。改设置后有决定对不上时，会提示并可以一键改回原来的设置。文件在磁盘上被改过后重新比较，上一版里还对得上的决定会被带回来。
- 「最近比较」显示审阅进度，例如“已审 8/19”。修订审阅的导航角标也改成“已审 / 总数”。

## Word 导出与比对报告

- 「导出」挪到右栏顶部，富文本和修订审阅都能用。
- **Word 修订稿 · 带审阅批注**：真正的 Word 修订（`w:ins` / `w:del` / 格式修订），作者是修改方（默认读取对方文件的“最后修改者”，可改）；你的每个决定是一条署你名字的批注，律师可以在 Word 里继续逐条接受或拒绝。
- **Word 审阅后定稿 · 保留记录**：接受的写成正文，拒绝的恢复原文，待议的仍是修订，批注全部保留。导出定稿前必须处理完所有修订（可以一键把剩下的标为待议）。
- **比对报告 PDF**：首页先列需要留意的条款，然后是比对凭证（文件、SHA-256、比较范围、条件、对齐方式）、按条款分组的变更表（含审阅人、时间、备注），最后附修订全文。
- 风险条款的批注前会加【风险·金额】这类标签。
- 复制摘要也按条款分组，并带上需要留意的条款、审阅进度和比较条件。

## 风险摘要（需要留意）

比较完成后，命中规则的变化放在右栏最上方。完全靠规则判断，离线完成，每条都写明为什么被挑出来：

- **金额与付款**：带货币单位或百分比的数字变化，或者出现在费用、价款、支付类条款里的数字变化，并算出差额和幅度（如 120,000 → 198,000 元，+65%）。
- **日期与期限**：具体日期的提前 / 推后，以及“日、天、个月、年”等期限的延长 / 缩短，能识别“十二个月”这样的中文数字。“第 3 条”这类条款编号不会被当成金额。
- **自定义关键词**：默认预置“违约、赔偿、责任上限、解除”，可在设置 → 风险里增删。

## 比较范围更完整，结论更诚实

- **页眉、页脚、脚注参与比较**，作为独立区段显示，可以折叠，变更列表里也单独成组。Word 读取对应部件；PDF 识别每页反复出现的顶部 / 底部文字（单页 PDF 看位置和字号），并识别页面下部的脚注。只有页码的行不比较。
- “内容完全一致！”改为“在已比较的范围内未发现差异”，并列出没有比较的内容（批注、图片内容、页码等）。
- Word 与 PDF 互比时，顶部常驻“跨格式比对”提示，说明 PDF 文字是从版面推断的、格式差异是否检测，并可以一键打开格式检测。
- 右栏新增「比较范围与条件」，相当于这次比较的凭证。
- OCR：修复“取消识别”后识别结果仍可能冒出来的问题；按页显示识别置信度，没认准的字用虚线标出。

## 看得懂、找得到

- **条款锚点**：每处变更挂上所属条款，变更列表按条款分组；审阅栏上也显示当前这处在哪一条。
- **差异语义色**：删除、新增、修改、格式、移动各有一套颜色，并且都有线型：删除 = 删除线，新增 = 下划线，移动 = 双线，格式 = 虚线下划线，色弱也能区分。品牌绿、PDF 角标不再借用差异色。
- 差异概览改成五格，同时是图例和筛选器：点一格只看这一类，地图和上一处 / 下一处也跟着筛选。
- 差异地图并入滚动条：可以拖动、点击跳到附近的差异；差异超过 200 处时改画密度条。大量重复的同一种改动会在列表顶部合并显示。

## 外观、布局与无障碍

- 保留绿色、圆角和吉祥物；去掉按钮的全大写，立体底边只留给主操作按钮，正文字重降一档，三级灰加深到 4.5:1 以上；颜色 token 改为语义命名。
- 比较结果页不再出现吉祥物；审阅完成的彩纸改为设置里的选项，默认关闭。
- 深色模式下文档纸张默认保持浅色（和打印出来的合同一致），可以在设置里改为跟随主题。
- 首页：两份文档都就位后才出现「开始比较」；新增「用示例合同试一下」；去掉看起来能点、其实不能点的模式胶囊。
- 窗口宽度在 1180px 以下时，右栏变成按需打开的抽屉，左栏收成图标栏，正文不再被裁切。
- 设置改为左右两栏（通用 / 审阅 / 风险 / 快捷键 / 关于与更新），右上角可以关闭，Esc 也能关。
- 所有弹窗：焦点限制在弹窗内、Esc 关闭、关闭后焦点回到原来的按钮；可折叠卡片可以用键盘展开；提示消息能被读屏读出。

## 快捷键变化

- 新增 H：标为待议；N：写备注。
- N 以前等同于“拒绝”，现在用来写备注；拒绝请用 R。

## 已知限制

- 导出的 Word 是根据比较内容重新排版的：页面设置、部分编号样式和图片可能与原件不同。页眉页脚放回 Word 的页眉页脚，脚注列在文末。在原文件上直接修改留到后续版本。
- 多人审阅只支持同一台电脑（换审阅人后，旧决定保留原来的署名）。
- 风险摘要只靠规则，会有误报和漏报。
- WPS 对修订和批注的显示需要在实际环境中再确认一次。

- 新增 `npm run typecheck`（TypeScript 类型检查）。
