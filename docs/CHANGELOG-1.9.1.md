# DocDiff 1.9.1

设置、审阅结论、往来稿和模板都原样保留。界面先在 Figma 里确认过（「方案 · 1.9.1」F1–F8），组件库和规范已同步到 3.3。

## 往来稿：删除某一版、给某一版起名

- 版本链里每一行悬停时右侧出现「…」：**起名…**、**删除这一版**。
- 起名：显示为「V3 · 对方第二次修改」，编号始终保留，工具栏仍是「V2 → V3」，悬停能看到名称。名称只用于显示，不改文件名。回车保存、Esc 取消，清空就只显示文件名。
- 删除：后面的版本往前重新编号（V1–V5 删掉 V3，原来的 V4、V5 变成 V3、V4）；以它为一侧的审阅记录一起去掉，其余轮次保留；正在比的一对用到它时回到最新两版。10 秒内可以撤销（比较页里按 U 也行）。至少留两版，只剩两版时「删除这一版」置灰。

## 条款编号和 Word 一致

- 章节标题带自动编号时显示编号（如「10.」），并参与计数：以前 9.5 会显示成 1.36，现在和 Word 一样。
- 读 Word 编号的起始值、中途重新起编，以及共用同一个编号定义的列表接着数。
- 编号只是显示，不算差异（和以前一样）。

## 查找

- 比较页按 Ctrl / ⌘ + F 打开查找栏：搜当前模式里两侧的文档文字，高亮所有匹配，Enter / ↓ 下一个，Shift + Enter / ↑ 上一个，显示“第 i / n 个”，Esc 关闭。
- 富文本、纯文本、修订审阅、OCR 文本里可用；不过滤右侧的变更列表。折起来的“未变化段落”不在搜索范围里。

## 弯引号和直引号

- 比较设置里新增「忽略引号样式（直引号 / 弯引号）」，**默认开**：`Company's` 和 `Company’s` 不再算一删一增。比较范围的“条件”里写明了这一条。

## 存为往来稿更顺手

- **首页**「最近比较」里选「存为往来稿」：留在首页，这一行显示“正在存为往来稿…”，存好后提示，不打开比较。
- **比较页**：点工具栏的文件片，小菜单里有「换一个文件…」「存为往来稿」，所有模式都有，不管有没有修订。把文件拖到文件片上仍是直接替换。

## 首页

- 整页不滚动：新比较固定在上面，左右两张卡片撑满到底栏，内容多了在卡片里滚动；窗口太矮时退回整页滚动。
- 左边卡片改成页签「最近比较 | 往来稿」，第一次默认最近比较，之后记住上次选的。
- 三个模块只用左上角的小图标块区分：新比较蓝、往来稿紫、模板橙；鼠标移进去边框变成模块色，图标轻轻跳一下。
- 底栏上的对对露出约 60%，不再像被切掉一半；空放置区换成不带类型的通用文档图标。

## 更细的地方

- **完成页**：“结论目前只记在 DocDiff 里”的说明收进 ⓘ，只留一行状态。
- **图鉴**：没见过的对对改成轮廓线剪影（深色模式里不再像坏图）。
- **提示条**：首页的提示让开底栏；撤销提示和普通提示叠放、对对的气泡在提示出现时收起，不再互相遮挡。

## 小彩蛋

- 比较或识别超过 5 秒，对对举着小牌子轮换讲一条小技巧。
- 52 个对对都见过以后，关于页出现金色描边的对对，图鉴标题旁多一枚徽章。
- 两份一字不差时撒一小把彩纸（只在第一次，跟着彩纸开关）。
- 关于页写着对对从哪天开始陪你。
- 23 点后、深色模式时，首页对对戴睡帽说晚安（合并了原来的“深夜”和“深色模式”两个彩蛋）。

## 记录，下一轮再定

- 整段字体、字号不同（一份是另一份另存或转换出来的）时，格式变化会把文字修改淹没。已用合成样本复现：三段同样的文字、整段换了字体和字号、只有一处改了天数，结果是 5 处格式变化、1 处文字修改。
