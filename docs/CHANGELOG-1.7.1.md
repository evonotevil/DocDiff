# DocDiff 1.7.1

修正 1.7 的两处显示问题，同步更新《DocDiff 设计规范》到 3.0.1。比较、导出、审阅都没有变，覆盖安装即可。

## 侧栏收起时，macOS 红绿灯压在分隔线上

- 侧栏收起后，工具栏铺满整个窗口宽度，红绿灯落在工具栏左端；收起 / 展开侧栏的按钮排在红绿灯右侧，是工具栏的第一个按钮。
- 收起后的图标栏从工具栏下方开始，分隔线不再穿过红绿灯。
- 全屏时红绿灯隐藏，工具栏左边不再留空。
- Windows / Linux 用同一种结构（工具栏右边照旧给系统按钮留位置）。

## 文件片里的“DOCX”被挤掉一个字母，长文件名看不出版本

- 类型标签和“原始 / 修改后”不再被压缩。
- 文件名拆成两段：开头放不下时用省略号截掉，结尾一段（扩展名前 6 个字 + 扩展名）永远完整显示，例如“261012 奶龙x塔塔 品…（标黄）.docx”。
- 文件片最宽从 240 放宽到 280。
- 窗口较窄时，“复制摘要”只显示图标，文件片不显示“原始 / 修改后”；中间的上一处 / 下一处不会再被挤压。

## 设计规范 3.0.1

- 布局：侧栏收起时工具栏铺满；新增“窗口按钮区”规则（macOS 红绿灯、Windows 标题栏按钮）。
- 工具栏、文件片组件：补充宽度和压缩顺序；样板同步更新。
- 走查清单新增两条：长文件名、窗口按钮区在展开 / 收起 / 全屏三种状态下的检查。
