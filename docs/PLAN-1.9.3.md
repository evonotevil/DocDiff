## 3. 快捷键好发现（F12）

- 有快捷键的按钮，悬停提示统一写成「名称 · 快捷键」（如「交换左右文档 · ⇧⌘S」）；悬停提示是系统自带的提示框，没有快捷键的照旧只写名称。
- 按 `?`（Shift + /）弹出快捷键速查（和 设置 · 快捷键 同一张表）；在输入框里不触发；首页和比较页都能用。
- 设置 · 快捷键 顶部写一句“随时按 ? 打开这张表”。

## 4. 格式变化太密（F13）

- 不改比较逻辑。富文本 / 修订审阅里，格式变化占全部差异一半以上、至少 10 处，且大多数是同一类整段格式（字体或字号）时，变更列表顶部出现一条提示：「N 处是格式变化，多数是整段字体不同」+「只看文字修改」按钮（= 关掉「检测格式变化」）。
- 关掉后提示变成「已隐藏格式变化 · 恢复」，可以撤回；记在这一对文件上（换文件后重新判断）。

## 5. 模板 / 往来稿演示（F14）

- 空的模板 / 往来稿卡片里「看看怎么用（30 秒）」，点开弹窗播放；有内容后卡片标题旁 ⓘ 里也能再看。不自动弹。
- 用真实界面组件演出来：弹窗里是缩小的 DocDiff 画面（真实的卡片、按钮、放置区、版本链、检查器组件），模拟光标移动和点击波纹、镜头推近、每步一句字幕；中英文、深色模式自动跟随。
- 约 30 秒，底部步骤点：暂停 / 重播 / 点某一步跳过去；“减少动态效果”时一步一张静态画面、点下一步。
- 模板：① 新建模板，把自己的标准合同存进来 → ② 对方发来改稿，只拖进对方的文件 → ③ 自动认出是哪份模板并开始比较。
- 往来稿：① 比较完存为往来稿 → ② 对方又发来一版，加入新版本 → ③ 在版本链里切换任意两版 → ④ 新一轮里看到「上轮」提示和条款历史。
- 文件名、内容一律虚构示例。
