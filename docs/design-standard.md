# DocDiff 设计语言 v2.0

自 1.6.2 起生效，取代 1.6.1 的《组件标准 v1.0》。完整版（带可操作的组件样板和界面示意）见 `docs/design-language.html`。代码里的 token 都在 `renderer/src/styles.css` 顶部。

## 定位：友好的外壳，严谨的纸面

- **外壳**：首页、左栏、按钮、右栏、审阅栏、空状态。多邻国原色、2px 边框 + 4px 立体底边、900 / 800 字重、会回应的吉祥物“对对”。
- **纸面**：文档正文和差异标记。白纸、宋体、宽行距，差异用四种校验过的颜色加线型。
- 判断：让人“去做”的属于外壳；让人“去读”的属于纸面。差异地图和变更列表用外壳的形状、差异色的颜色。

## 五条原则

1. **纸是主角。** 阅读时界面让路；结果页最亮的是文档里的差异。
2. **能按的会动。** 能点的都有 2px 边框 + 4px 立体底边，按下下沉；只展示信息的没有底边。
3. **颜色有职责。** 原色属于操作和模式；差异色只属于差异；黄色只表示“需要你看一眼”。
4. **每一步都有回应。** 100 毫秒内给出看得见的回应；重要进展有一次小庆祝，不打断阅读。
5. **说人话。** 按钮写动作，数字带单位，提示先说发生了什么、再给一个操作。

## 视觉层级

| 级别 | 内容 | 手段 |
|---|---|---|
| L1 | 正文与差异 | 最高对比度；宋体 15–16px；差异用底色 + 线型 |
| L2 | 当前这一处 | 浅蓝底 + 2px Macaw 蓝边；文中闪一次 |
| L3 | 导航与分组 | 900 字重、深灰；靠字重不靠颜色 |
| L4 | 辅助信息 | 12px / 800、三级灰 |

每一屏只有一个主角色：首页是“开始比较”，结果页是文档里的差异，审阅页是进度和三个决定按钮，完成页和空状态是“对对”和一句话。

## 排版

- 界面：Nunito + 思源黑体；文档：宋体（Times New Roman / Songti SC / SimSun）。
- 字号七级：28 / 20 / 16 / 14 / 13 / 12 / 11。字重：标题 900，按钮和标签 800，正文 400–700。
- 中文不加字距；中文与数字、英文之间空一格；标点全角；对齐的数字用等宽数字。
- 行高：界面 1.5，文档 1.8，标题 1.2。

## 留白与布局

- 间距是 4 的倍数：元素内部 4 / 8，组内 8 / 12，组与组 16 / 24，区块 32 / 48。
- 两种密度：首页、弹窗、空状态宽松（控件 40–48px）；右栏、工具条、列表紧凑（控件 32px，列表行 40px）。
- 圆角：8 标签 / 键位，12 小按钮 / 输入，16 按钮 / 卡片，18 面板，20–22 弹窗 / 放置区。内层圆角 = 外层圆角 − 间距。
- 边框一律 2px；立体底边 4px（小按钮 3px）；只有文档里的表格线用 1px。
- 结果页：左栏 200–228，文档区自适应（纸张最宽 860），右栏 316–340；窄于 1180px 时左栏收成图标、右栏变抽屉。

## 颜色

外壳（多邻国原色）：

| 颜色 | 职责 |
|---|---|
| Feather 绿 #58cc02 | 主操作、接受、进度、品牌、“图像”模式 |
| Macaw 蓝 #1cb0f6 | 选中、文件操作、DOCX、焦点框、“富文本”模式 |
| Cardinal 红 #ff4b4b | 拒绝、出错、PDF |
| Bee 黄 #ffc800 | 待议、需要留意、警告、“修订审阅”模式 |
| Beetle 紫 #ce82ff | “OCR 文本”模式 |
| Fox 橙 #ff9600 | “文件详情”模式 |

差异色（多邻国色系，单独校验：色弱最小差 8.5，正常视力最小差 20.2）。每种四个色阶，和多邻国按钮一样：

| 差异 | 亮面（色块、圆点、刻度） | 底边（线条、描边） | 墨色（文字） | 浅底 | 文中高亮 | 线型 |
|---|---|---|---|---|---|---|
| 删除 | #fc3c40 | #d92a2f | #c0061e | #feebe9 | #fed2cd | 删除线 |
| 新增 | #1bcba0 | #0da481 | #016f55 | #daf8ec | #b0eed7 | 下划线 |
| 格式 | #3f83f8 | #2a6be0 | #0056d7 | #e9f1fe | #cddffd | 虚线下划线 |
| 移动 | #d052c8 | #b03aa8 | #ab00a5 | #ffe8fb | #facef4 | 双线 |

- 修改 = 删除 + 新增，用红绿各半表示，不单独配色。
- 薄荷绿在白底上只有 2.1:1：亮面只用在有文字标注的地方，地图刻度加底边描边，亮面上的字用深色 #04382b。
- 深色模式：亮面和底边不变，墨色 / 浅底 / 高亮换成深色版本，文字对比度 ≥ 5:1。

## 交互反馈

| 状态 | 表现 | 时长 |
|---|---|---|
| 悬停 | 提亮 / 浅灰底 | 即时 |
| 按下 | 底边 4px → 2px，下沉 2px | 100ms |
| 选中 | 蓝边 + 浅蓝底，弹一下；文中闪一次 | 150 / 600ms |
| 键盘焦点 | 2–3px Macaw 蓝外框 | 即时 |
| 做出决定 | 审阅栏整条变色、结论弹出、圆点变 ✓ / ✕、220ms 后跳到下一处 | 250ms |
| 过半 / 完成 | 提示“过半了！”；完成页“对对”欢呼 + 彩色统计卡 | 3.2s |

缓动先快后慢，弹出带一次轻微过冲；系统开启“减少动态效果”时全部关闭。

## “对对”出现的地方

开心：首页（配一句话）· 思考：比较中、识别中 · 欢呼：没有差异、审阅完成 · 尴尬：读不了文件、出错 · 犯困：等待 OCR、已取消。不出现在文档旁边。

## 上线前检查清单

1. 能点的都有立体底边，不能点的都没有。
2. 这一屏只有一个主角色（实心绿按钮最多一个）。
3. 颜色没有兼职：黄色只表示需要留意；差异色只出现在差异上。
4. 字号在七级之内，字重只用 400 / 700 / 800 / 900。
5. 间距是 4 的倍数，边框 2px，圆角在规定的档位里。
6. 每个操作都有回应，并且能用键盘完成。
7. 空状态有“对对”、一句话和一个操作；报错说清楚怎么了、怎么办。
8. 深色模式看过一遍。
9. 英文界面看过一遍，没有文字被截断。
