## 定位：友好的外壳，严谨的纸面

DocDiff 是一个让人放心的比对工具，同时带着多邻国的性格。

- **外壳**：首页、侧栏、工具栏、检查器、审阅栏、空状态。多邻国原色、圆头粗体、2px 边框加 4px 立体底边、会回应的吉祥物“对对”。
- **纸面**：文档本身和纸上的差异标记。白纸、宋体、宽行距，差异用四种多邻国原色加四种线型。
- 判断方法：让人“去做”的属于外壳，让人“去读”的属于纸面。

## 五条原则

1. **纸是主角。** 工作时界面让路，结果页上最醒目的是纸上的差异。
2. **能按的会动。** 能点的东西有立体底边，按下会下沉；只展示信息的东西是平的。
3. **颜色有职责。** 每种颜色只做一件事：绿是前进，蓝是选中，黄是留意，四种差异色只属于差异。
4. **每一步都有回应。** 100ms 内给出看得见的反馈；重要进展有一次小庆祝，但不打断阅读。
5. **说人话。** 标题用名词，按钮写动作，数字带单位，出错时先说发生了什么，再给一个办法。

### 差异色

四种差异各取一个多邻国原色，每种六个色阶。修改 = 删除 + 新增，用红绿各半表示，不单独配色。

| 差异 | 色名 | 亮面 | 底边 | 墨色 | 文中高亮 | 浅底 | 线型 |
|---|---|---|---|---|---|---|---|
| 删除 | Cardinal | #ff4b4b | #ea2b2b | #c41e1e | #ffdfe0 | #fff0f0 | 删除线 |
| 新增 | Mask | #89e219 | #58a700 | #3c6b00 | #d7ffb8 | #effde4 | 下划线 |
| 格式 | Humpback | #2b70c9 | #1f5ba8 | #1f5ba8 | #dbe7f8 | #eef4fc | 虚线下划线 |
| 移动 | Beetle | #ce82ff | #a560e8 | #7a2fc4 | #f3e3ff | #faf3ff | 双下划线 |

- 四种亮面两两比较：色弱模拟下最小差 12.7，正常视力最小差 24.4。红和绿靠亮度区分（一深一浅），再加线型，任何人都不需要只靠颜色判断。
- **亮面**只用于 8px 圆点、22px 编号圆、地图刻度。新增的亮面在白底上只有 1.6:1，必须带 `diff-ins-lip` 描边。
- 亮面上的符号：删除、格式用白色；新增、移动用深色（`diff-*-glyph`）。
- **纸上的文字**一律用墨色，底色用文中高亮，再加线型。墨色在高亮上 ≥ 5.3:1。
- 深色模式：亮面和底边不变；墨色、高亮、浅底换深色版本，文字对比度 ≥ 5.9:1。

### 已知的品牌例外

白字在 Feather 绿上只有 2.1:1，在 Macaw 蓝上 2.4:1。这是多邻国按钮的标志写法，DocDiff 保留它，但加两条限制：这两种实心按钮的字必须 ≥ 15px 且 800 字重；按钮之外不允许白字压在绿或蓝上。

批注里对方的 Fox 橙字（作者归属、纸边批注标上的数字）白底约 2:1，低于 4.5:1。保留它作为批注的身份标识，但只用在这两处，不用于其他要读的文字（1.9.8）。

类型徽章（DOCX / PDF / TXT）不用亮色底，用墨色底：`badge-docx` #0c6fa6、`badge-pdf` #c41e1e、`badge-txt` #6f6f6f，白字 ≥ 5:1，浅色、深色同值（1.8.1）。

## 字体

界面用 **Nunito**（圆头，接近多邻国的 Feather Bold）配思源黑体；文档用宋体（Times New Roman / Songti SC / SimSun）。

| 角色 | 样式 | 颜色 | 用在 |
|---|---|---|---|
| 展示 `display` | 32 / 900，行高 1.15 | title | 首页、完成页，一屏最多一处 |
| 标题 `title` | 22 / 900 | title | 页面和弹窗标题 |
| 区块标题 `section` | 13 / 800 | text-2 | 差异、原始文档、审阅人 |
| 正文强 `body-strong` | 15 / 700 | eel | 行、导航项 |
| 正文 `body` | 15 / 400 | eel | 说明段落 |
| 按钮 `button` | 15 / 800（小 13 / 800） | 随按钮 | 所有按钮 |
| 说明 `caption` | 13 / 700 | text-2 | 时间、作者、行尾信息 |
| 分组标题 `group` | 12 / 800 | text-2 | 条款名、页眉，吸顶 |
| 数字 `number` | 900，等宽数字 | title | 计数、金额、进度 |
| 文档 `doc` | 宋体 15 / 1.85 | doc-ink | 纸上的正文 |

- 字重只有 400 / 700 / 800 / 900，不用 500、600。
- 一屏最多三种字号。结果页是 13、15 和文档字号。
- 英文按钮和标题句首大写，不全大写、不加字距（见「英文」）；中文不加字距、不变形。
- 中文与数字、英文之间空一格：“共 19 处”。标点全角；数字区间用“–”。

### 所有数值只用变量（1.9.1 / 1.9.4）

- 字阶：32 / 22 / **20** / 18 / 15 / **14** / 13 / 12（加粗为 1.9.1 新增：20 用于完成页标题、空状态标题和卡片里的大数字；14 用于英文按钮、气泡和偏小的正文）。变量 `--fs-<px>` 由 `npm run tokens` 从 `design-tokens.json` 生成。
- 圆角：新增 `radius-2xs` 3、`radius-xs` 6；纸用 `radius-l`，首页放置区用 `radius-xl`。
- 时长：新增 `dur-mascot-quick` 250、`dur-mascot` 450、`dur-mascot-long` 900、`dur-moment` 1200、`dur-spin` 1000、`dur-loop` 3000。
- `node scripts/check-tokens-usage.mjs` 检查 `styles.css`：写死的字号、圆角、时长都会报错。例外只有文档排版（纸上的标题字号跟原文档走）、等宽字体、品牌字标、“减少动态效果”，在行尾标 `token-exempt`。
- 以前用到但没定义的 `--pnl-hover`、`--r-pill` 已定义。
- 1.9.4 起再加四类：**间距**只用 `--space-*`（刻度见「间距」）；**控件高度** 48 / 36 / 30 只用 `--control-l` / `--control-m` / `--control-s`；**颜色**只用颜色变量（提示条边框、遮罩、实心底白字也有了变量）；**用到的变量必须有定义**。圆角变量只用 `--radius-*` 一套名字，旧名 `--r-s` / `--r-m` / `--r-xl` 删掉。
- 检查跟着扩大：`check-tokens-usage.mjs` 查字号、圆角、时长、间距、控件高度、颜色、未定义变量；`check-native-controls.mjs` 查原生控件（见「表单控件」）；`audit-ds` 走查脚本逐屏量每个能点的元素，高度、圆角、字重不在刻度上就报出来。例外仍只有文档排版、等宽字体、品牌字标、“减少动态效果”，标 `token-exempt`。

## 品牌

DocDiff 的品牌只有三样东西：**标志**、**字标**和吉祥物 **“对对”**。它们画的是同一个角色：一张会笑的纸。所有文件都在 `docs/brand/` 里，与安装包里的应用图标是同一份图形（`build/icon.png`、`build/icon-win.png`、`renderer/src/assets/logo-mark.svg`）。

### 字标

- 字体 Nunito 900，字色 Feather `#58cc02`，字距 −2%。
- 比例：标志高 1，字号 0.62，标志和字之间 0.16。
- 界面里的尺寸：首页顶栏 26px，侧栏标题行 22px。
- 首页顶栏的字标左边缘和下面内容（最宽 1080、左右 32）的左边缘对齐；窗口窄时 Mac 上退到红绿灯右侧，不和红绿灯重叠。顶栏高度不变（1.9.9）。
- 侧栏顶部：Windows 字标和收起按钮同一行；Mac 第一行留给红绿灯，只放收起按钮，字标在第二行。模式列表上面不写「比较模式」小标题（1.9.9）。
- 只写 “DocDiff”，D 和 D 大写，中间不加空格；中文场合也不翻译。
- 副标题（如首页的“离线文档比对”）用 12/800、次要灰，放在字标右侧基线对齐，不属于字标本身。

### 留白与最小尺寸

- 四周留白至少是标志高度的 25%，里面不放任何文字或图形。
- 图形标志在界面里不小于 20px 高；字标不小于 20px 高。16px 及以下（任务栏、网页图标）一律用应用图标，由系统渲染。
- 打印时图形标志不小于 8mm。

### 颜色与背景

| 背景 | 用哪个 |
|---|---|
| 白色、Polar、浅灰 | `wordmark.svg` |
| 深色界面（`surface` 深色 `#131f24`） | `wordmark.svg`，绿色字在深底上对比度足够 |
| Feather 绿、彩色、照片 | `wordmark-white.svg` |

### 不要

- 不要改标志里的任何颜色，也不要换成单色或描边版本。
- 不要拉伸、压扁、旋转整个标志，也不要拆开两张纸单独用。
- 不要给标志加投影、外发光或描边（应用图标由系统加的阴影除外）。
- 不要把字标换成其他字体或改字重，不要在字标后面加口号。
- 不要把绿色字标放在 Feather 绿上。

### 吉祥物“对对”

“对对”就是标志里那张纸：白纸、绿色折角、两只眼睛，多了两只绿色手臂和小脚。开心时的笑脸和标志一样，是一红一绿两段（1.9）。

| 表情 | 文件 | 什么时候出现 | 尺寸 |
|---|---|---|---|
| 开心 | `Mascot/duidui-happy.svg` | 首页（配一句话的气泡） | 124 |
| 思考 | `Mascot/duidui-think.svg` | 比较中、识别中 | 96 |
| 欢呼 | `Mascot/duidui-cheer.svg` | 没有差异、审阅完成 | 96 / 120 |
| 犯困 | `Mascot/duidui-sleepy.svg` | 等待 OCR、已取消 | 96 |
| 尴尬 | `Mascot/duidui-oops.svg` | 读不了文件、出错 | 96 |

![欢呼](brand/Mascot/duidui-cheer.svg)

- 表情只有这五种，不改身体和配色。1.9 起可以换手臂、视线、嘴型、眨眼，配小道具（同一时间最多一件），动作表见下面「对对出来走走（1.9）」。
- 动画只用位移、旋转、缩放（≤ 6%）、换手臂和眨眼；单次 ≤ 1.2 秒，不循环抖动（打盹的 2px 呼吸除外）。“减少动态效果”时只显示静态图。
- 不出现在纸面旁边、菜单和工具栏里。弹窗里只在标题左侧放一个 36px 的静态对对（1.9）。
- 每次出现最多配一句短话；非用户触发的出场 30 秒内最多一次。

### 对对出来走走（1.9）

## 布局

### 空间结构

结果页固定由四部分组成：**工具栏 + 侧栏 + 画布 + 检查器**。侧栏和检查器是同一种材质、同一种行、同一种选中态；画布上的纸是唯一的大面积白。

| 部分 | 回答的问题 | 内容 |
|---|---|---|
| 工具栏 | 这份比较整体怎么样 | 左：两个文件片和交换；中：上一处 / 下一处（审阅时换成进度条）；右：比较设置、复制摘要、导出 |
| 侧栏 | 去哪里 | 六种比较模式、新建比较、设置 |
| 画布 | 读什么 | 原始文档和修改后文档的纸，差异地图 |
| 检查器 | 看什么 | 筛选片、差异清单、这一处的详情；底部一行“比较范围” |

### 功能归属

每个功能只有一个家。新功能先在这张表里找到位置，找不到再讨论。

| 功能 | 位置 | 理由 |
|---|---|---|
| 两个文件、交换 | 工具栏左侧 | 它们定义了这份比较 |
| 上一处 / 下一处 | 工具栏中间；审阅时换成进度条 | 导航整份比较 |
| 导出、复制摘要 | 工具栏右侧；导出是唯一的绿色按钮 | 作用于整份比较 |
| 比较设置 | 工具栏按钮 → 弹出层 | 低频，改完就关 |
| 收起 / 展开侧栏 | 侧栏标题行右端 | 开关挨着它控制的东西 |
| 收起 / 展开检查器 | 工具栏最右端 | 与检查器同一侧，位置固定 |
| 比较范围 | 检查器底部一行摘要 → 弹出层（操作叫「更改」，1.9.8） | 一直在，但不占地方 |
| 差异概览 | 检查器顶部的一行筛选片 | 数字和筛选本来就是一件事 |
| 需要留意 | 筛选片“需要留意 7” + 行尾的 ⚠ | 是差异的属性，不是另一份清单 |
| 差异清单 | 检查器主体，占满剩余高度 | 检查器只做一件事 |
| 全部接受 / 全部拒绝 | 审阅时检查器标题右侧的“…”菜单 | 低频且有风险 |

### 网格

- 8pt 网格，最小单位 4。
- 三栏共用两条水平线：**56**（`toolbar-h`，工具栏底边）和 **96**（`header-line`，区块标题底边）。三栏的内容都从 96 开始。
- 栏宽：侧栏 232 · 画布自适应（纸最宽 860）· 检查器 320。窗口窄于 1180px 时，侧栏收成 72 宽的图标栏，检查器变成抽屉。
- 侧栏和检查器左右内边距都是 16，行高都是 40，行圆角都是 12。
- 控件只有三种高度：48 / 36 / 30；筛选片 28。

### 侧栏的收起与展开

两侧都可以手动收起，开关在固定位置，不再用贴在画布边缘的浮动把手。

| | 侧栏 | 检查器 |
|---|---|---|
| 收起后 | 变成 72 宽的图标栏，六个模式图标保留，仍可切换模式；名称放进悬停提示 | 完全隐藏，画布占满 |
| 开关 | 展开时：侧栏标题行右端；收起时：工具栏最左端的第一个按钮（macOS 在红绿灯右侧） | 工具栏最右端、导出之后的图标按钮 |
| 快捷键 | ⌃⌘S（Windows：Ctrl+Alt+S；Ctrl+Shift+S 留给“交换左右”） | ⌥⌘I（Windows：Ctrl+Alt+I） |
| 收起时 | — | 工具栏的上一处 / 下一处和“第 n / N 处”照常工作；审阅栏照常浮在纸上，可以继续审阅 |
| 记忆 | 状态记在本机，下次比较沿用 | 同左 |
| 动画 | 宽度过渡 `dur-advance` 220ms；“减少动态效果”时直接切换 | 同左 |

- **收起时工具栏铺满整个窗口宽度**，图标栏从 56 线下面开始，侧栏和画布之间的分隔线也从 56 往下画。这样窗口顶部是一条完整的工具栏，开关和红绿灯在同一行。
- **窗口按钮区**：macOS 红绿灯在左上角（位置 20, 20），侧栏展开时侧栏标题行左边留 96，收起时工具栏左边留 84；全屏时红绿灯隐藏，这两处留白都去掉。Windows / Linux 的系统按钮在右上角，工具栏右边留 150。任何内容都不能压在窗口按钮区里。
- 开关是 36 的界面图标按钮（`wolf`，悬停 `hover` 底），图标为“侧栏”线框图，左右镜像；`aria-expanded` 随状态变化，提示里带快捷键。
- 窗口窄于 1180px：侧栏默认收起为图标栏，工具栏里的“复制摘要”只显示图标，文件片不显示“原始 / 修改后”；检查器默认隐藏，打开时以抽屉形式盖在画布上（`surface` ＋ `shadow-float`），点画布或按 Esc 关闭。窗口变宽后恢复用户上次手动设置的状态。
- 检查器内部不再有可折叠的面板：只有筛选片、差异清单和底部的比较范围。分组标题吸顶，但不折叠。
- 纸面里页眉、页脚、脚注区段的折叠保留，它属于文档，不属于栏。

### 页面模式的范围

- 图像和 OCR 逐页渲染，没有页数上限。两份文档任何一份超过 300 页时，开始前先显示“页码范围”确认：两份各多少页、预计多久、比较全部还是只比一段。
- 只比较了一段时，画布顶部（OCR 在识别质量旁）写明“只比较了第 a–b 页，共 n 页；其余页面没有比较”，并给“更改”。页码按原文件的实际页码。
- 文字模式（富文本、纯文本、修订审阅）一直比较全文，不受这个范围影响。

### 平面与边界

只有五种平面。**边框只画在平面相接的地方**，平面内部靠留白和分组标题区分，不画卡片。

| 平面 | token | 用在 | 边界 |
|---|---|---|---|
| 侧面 | `side` | 侧栏、检查器 | 与画布相接处 2px `swan` |
| 工具面 | `surface` | 工具栏 | 底边 2px `swan` |
| 画布 | `canvas` | 文档区底色 | 无 |
| 纸 | `paper` | 文档 | 2px `swan`，圆角 `radius-l` |
| 浮层 | `surface` + `shadow-float` | 弹出层、审阅栏、弹窗 | 2px `swan` + 阴影，圆角 `radius-float` |

检查器里没有面板边框。需要强调的只有当前选中的那一行。

### 间距

- 刻度只有 4 / 6 / 8 / 12 / 16 / 24 / 32 / 48（变量 `space-1` / `space-1-5` / `space-2` / `space-3` / `space-4` / `space-6` / `space-8` / `space-12`）。6 是 1.9.4 加的，只用在图标和文字之间、紧挨着的一对小元素之间；10、20 这类不在刻度上的值不再出现。4px 以下的光学微调不算间距；负间距（抵消内边距）按刻度取值。
- 元素内部 4 / 6 / 8，组内 8 / 12，组与组 16 / 24，区块 32 / 48。
- 两种密度：首页、弹窗、空状态宽松（控件 48）；工具栏、侧栏、检查器紧凑（控件 36 / 30，行 40）。控件只有 48 / 36 / 30 三个高度，行（导航项、设置页签、菜单项、检查器行）都是 40（1.9.4）。
- 内层圆角 = 外层圆角 − 间距。

### 首页（1.8 / 1.9.1 / 1.9.3）

- 第一次用和用过之后同一套三块（1.9.3，Figma F9b / F11）：新比较（Compact 放置区 + 「用示例合同试一下」）在上，下面「最近比较 | 往来稿」和「模板」两张卡片撑满到底栏，内容多了在卡片里滚动；卡片放不下 3 行（窗口高约 < 640）时退回整页滚动，卡片保持 3 行高。卡片底边离底栏留出探头对对的高度，对对不压在卡片上。第一次用时“全部在这台电脑上完成，不会上传”写在新比较标题旁。
- 模块卡片（组件 ModuleCard）：整块白底、2px Swan 边框、圆角 `radius-l`，没有灰色标题条；标题前是 28px 扁平插画（见「首页插画」），标题 18/900。三个模块外观一致，不用颜色区分（1.9.1 的“首页模块色”已去掉）。
- 卡片本身不能点，没有悬停效果；里面的行悬停 = `side` 浅灰底、圆角 `radius-m`。
- 下划线式页签（组件 Tabs）：选中 = Macaw 蓝文字 + 3px Macaw 下划线，和其他“选中”一致；计数是灰色文字，不加底色，0 不显示。左卡片「最近比较 | 往来稿」，第一次默认最近比较，之后记住；“清空”只在最近比较页签里，“已归档”只在往来稿页签里。
- 空卡片（组件 EmptyCard）：72px 插画 + 一句标题 + 一句说明；往来稿、模板（以及“最近比较”空着时）多一个「看看怎么用（30 秒）」，打开演示弹窗。卡片有内容后，标题旁的播放图标按钮也能打开演示。
- 名字相近的一对，共同部分只写一次，下面写不同的那一段；状态放在右侧固定一列（RecentRow）。（1.8）

### 底部元素的层级和间距（1.9.1）

| 层 | 元素 | 位置 |
| --- | --- | --- |
| 5 | 休息提醒卡片 | 右下角，距右 24，和提示条同一基线 |
| 4 | 完成瞬间的对对 | 贴在提示条左边 |
| 3 | 普通提示 | 有撤销提示时叠在它上方，间距 8 |
| 2 | 撤销提示 | 底部居中，距底 24；有底栏（首页）时距底栏 12 |
| 1 | 首页探头 / 气泡 | 提示条出现时气泡收起，探头不动 |
| 0 | 底栏 | 固定，不被遮挡 |

- 同时最多两条提示（一条撤销 + 一条普通），新的普通提示替换旧的。层级用变量 `--z-footer` / `--z-toast` / `--z-moment` / `--z-care`，位置用 `--toast-bottom`（首页 96，比较页 24）。

### 无障碍与适配（1.8.1）

- 要读的文字对比度 ≥ 4.5:1。hare 只用于占位、禁用和分隔符（→ ·），不承载时间、状态等文字。品牌例外仍只有字标和 Feather 绿 / Macaw 蓝实心按钮。
- 每页恰好一个 `main` 和一个 `h1`（老用户首页是“新比较”，比较页用只给读屏的标题）；弹窗标题 `h2`，弹窗里的区块标题 `h3`。
- 行内不嵌套交互：整行“打开”是铺满的透明按钮，“…”和改名框浮在上面；“ⓘ”是真正的按钮，说明用 `aria-describedby` 关联。
- 点击区域 ≥ 24×24；视觉小于 24 的控件用透明扩展区补足。
- 文档段落 `dir="auto"`；差异高亮 `unicode-bidi: isolate`。
- 放置区、卡片两列用 `minmax(0, 1fr)`，长文件名只省略不撑宽；较长的空态提示允许两行。
- 比较页双栏总宽 ≤ 2 × 860 + 16（栏间距 space-4，1.9.4 起从 18 并回刻度），居中。
- 切换语言后，应用生成的文案立即跟着切；英文按单复数写。

## 文字与命名

### 标题只有四级

| 级别 | 样式 | 结构 | 例子 |
|---|---|---|---|
| 页面 / 弹窗标题 | `title` 22 / 900 | 文字（＋右上角关闭） | 导出审阅结果、设置 |
| 区块标题 | `section` 13 / 800，`text-2` | 文字 ＋ 计数胶囊（可选）＋ 右侧最多一个操作 | 差异 19、原始文档、审阅人 |
| 分组标题 | `group` 12 / 800，`text-2` | 只有文字，滚动时吸顶 | 第二条 费用与支付、页眉 |
| 行 | `body-strong` 15 / 700，`eel` | 前置标记 ＋ 文字 ＋ 后置信息 | 富文本 19、120 → 198 ⚠ |

- 区块标题和分组标题**不带图标**。图标只出现在导航项、按钮和状态标记上。
- 同一级标题在每一栏长得一样，任何面板都不能自创标题样式。
- 标题不加句号、冒号、感叹号。

### 命名规则

- 用名词，2–4 个字，最多 6 个；不用“的”，尽量不用“与 / 和”。
- 同一个东西在每个地方叫同一个名字。
- 计数放在标题后的胶囊里，不写在括号里；筛选后显示“8 / 19”。
- 按钮写动作：“导出”“复制摘要”“开始比较”，不写“确定”。

### 定名

| 旧名（1.6.2） | 定名 |
|---|---|
| 差异概览 · 变更列表 | 差异（概览变成筛选片） |
| 修订列表 | 修订 |
| 需要留意（面板） | 筛选片“需要留意” |

### 文案

- 数字带单位：“19 处差异”“第 7 / 19 处”“3 页”。
- 提示先说发生了什么，再给一个办法：“读不了这个文件。它可能有密码，换一份试试。”
- 庆祝只用一句短话加一个感叹号：“过半了！还剩 9 处”“全部看完了！”
- 不用“您”，用“你”；不用“请”开头的命令句。

### 说明文字、菜单与提示（1.8）

- 说明文字最多一行，多的放进“ⓘ”（InfoTip）。
- 菜单 = 无标题的 Popover + MenuItem，上下各留 8px；“…”菜单宽 260。放不下时紧贴按钮上方 8px 弹出，按实际高度。
- 弹窗或弹出层开着时，键盘快捷键和菜单栏快捷键都不作用到后台（全屏切换除外）。
- 撤销提示在的时候，新的提示叠在它上面，不吞掉。
- 设置每页一屏放下：通用、审阅、审阅稿与定稿、风险、快捷键、存储、关于与更新。

### 英文（1.9）

美式英语，界面一律句首大写（含按钮、分组标题，不再用 CSS 全大写），术语用律师圈说法。日期、相对时间按 `Intl` 格式化。对方看得到的文字（审阅稿批注、报告）中性、专业，待议批注写 “Open for discussion”。自动检查：`node scripts/check-en.mjs`（术语、禁用词、全角标点）、`scripts/shots-19-en.cjs`（漏翻；`PSEUDO=1` 加长 40% 查溢出）。

#### 风格指南

1. **短**：按钮 1–3 个词，以动词开头（Create redline、Copy summary）。说明最多一行，多的放进 ⓘ。
2. **你**：对用户用 you。DocDiff 不自称 we；必要时直接说 DocDiff。
3. **主动语态，用缩写**：can’t、won’t、you’re。
4. **报错 = 发生了什么 + 怎么办**：
   - 例：“Couldn’t open this file. It may be password-protected — try opening it in Word first.”
   - 不说 sorry，不说 please，不说 successfully。
5. **少讲原理**：内部机制（对齐算法、区块数、哈希）不出现在界面上；需要时放进 ⓘ。
6. **标点**：
   - 文件名、按钮名用弯引号 “ ”。
   - 破折号 — 少用。
   - 列表不加句号；完整句子加句号。
7. **数字、日期、大小**：
   - 一律用 `Intl` 按系统地区格式化：Oct 26；跨年时 Oct 26, 2025；2 min ago；1.2 MB。
   - 单复数用 `Intl.PluralRules`（1.8.1 已有基础）。
8. **长度**：英文按比中文长 40% 预留。会换行的地方在设计里标明，其余单行省略并带悬停全名。
9. **大写**：分组标题不再用 CSS 全大写（现在英文会变成 COMPARISON MODES），改为句首大写的 13/800 小标题。
10. **对方看得到的文字**（批注、报告）：
    - 中性、专业，不带对对的语气。
    - 不出现 DocDiff 的界面用语。

## 交互与品牌

### 检查器和纸面是一体的

| 操作 | 回应 |
|---|---|
| 悬停清单里的一行 | 纸上对应文字出现 `macaw-tint` 描边，地图上对应刻度变粗；不跳转 |
| 点一行 | 纸面滚过去，对应处闪一次（`dur-flash`）；这一行成为选中态；工具栏显示“第 7 / 19 处” |
| 点纸上的差异 | 检查器滚到那一行并选中 |
| 点筛选片 | 清单、地图、上一处 / 下一处同时只看这一类。筛选片是唯一的筛选入口 |
| 做出决定 | 行尾出现 ✓ / ✕ / 待议，编号圆变成结论；审阅栏整条变色；`dur-advance` 后跳到下一处 |

### 反馈状态

| 状态 | 表现 | 时长 |
|---|---|---|
| 悬停 | `hover` 底色或提亮 | `dur-hover` 150ms |
| 按下 | 底边 4px → 2px，整体下沉 2px | `dur-press` 100ms |
| 选中 | 行和竖向导航（侧栏模式、设置页签）：白底 ＋ 2px `swan` ＋ 4px 底边，文字不变色；筛选片、单选卡片：`macaw-tint` ＋ Macaw 边；下拉菜单项：Macaw 字 ＋ 右侧勾；复选框：Macaw 底 ＋ 白勾 | 150ms |
| 键盘焦点 | 3px `macaw` 外框，偏移 2px；所有能聚焦的东西同一条规则，鼠标点击不出现（`:focus-visible`）。输入框聚焦时边框也变 Macaw | 即时 |
| 弹出 | 从 96% 放大到 100%，带一次轻微过冲 | `dur-pop` 250ms |
| 提示 | 底部居中的胶囊，停留后淡出 | `dur-toast` 3.2s |

缓动 `cubic-bezier(.2,.8,.2,1)`。系统开启“减少动态效果”时，所有动画、闪烁、彩纸都关闭，状态直接切换。

所有操作都能用键盘完成：↑ ↓ 换一处，R 拒绝，H 待议，A 接受，Esc 关闭浮层，⌘F 搜索纸面，⌃⌘S 收起 / 展开侧栏，⌥⌘I 收起 / 展开检查器。

### 危险操作与撤销

- 会一次改掉很多结论或删除保存数据的操作（全部接受、全部拒绝、重置所有决定、清理审阅记录）先弹“确认弹窗”，写清影响数量，按钮写具体动作。
- 能撤销的批量操作做完后，底部出现“撤销提示”，10 秒内点“撤销”或按 U，回到操作前的全部结论。
- 单个决定不弹确认，按 U 撤销。删除保存的记录不可撤销，所以确认按钮用红色。

### 保存状态

- 审阅结论、设置、最近比较都存在本机应用数据目录：先写临时文件再替换，保留上一份备份。
- 存成功不打扰；存不进去时画布顶部出现“保存警告”，审阅栏标“未保存”，给“重试保存”；下一次保存成功后自动消失。
- 任何用户数据都不能静默丢弃，不自动淘汰旧记录；清理由用户在“设置 → 审阅”里手动做，并且要确认。

### 颜色与触感预算

颜色和立体底边都要“花钱”。超出预算的设计不能上线。

| 预算 | 结果页上限 | 说明 |
|---|---|---|
| 实心绿 | 1 个 | 导出；审阅时是“接受” |
| 立体底边 | 2 处 | 按钮和当前选中项；筛选片、行、格子都是平的 |
| 饱和色块 | 2 块 | 模式图标、实心按钮；差异色只在 8px 圆点和 22px 编号圆上 |
| 带边框元素 | 12 个 | 只在平面交界处和浮层上 |
| 黄色 | 只用于小图标和计数 | 不做面板底色 |

首页、空状态、完成页是品牌时刻，预算放宽。

### “对对”和品牌时刻

性格集中在“开始”和“完成”，工作时安静陪伴。

| 时刻 | 表达 | 预算 |
|---|---|---|
| 首页 | “对对”和一句话、彩色模式图标、蓝色“选择文件”、48 高的“开始比较” | 宽松 |
| 比较中 / 空状态 | “对对”换表情 ＋ 一句话 ＋ 一个按钮 | 中等 |
| 工作中 | 只在按钮、选中项、模式图标上保留多邻国的形状 | 严格 |
| 做出决定 | 审阅栏变色、结论弹出、可选提示音 | 瞬时 |
| 完成 | “对对”欢呼、彩色统计卡、可选彩纸 | 宽松 |

“对对”的表情：开心（首页）· 思考（比较中、识别中）· 欢呼（没有差异、审阅完成）· 尴尬（读不了文件、出错）· 犯困（等待 OCR、已取消）。它不出现在纸的旁边。

### 弹出层、提示与撤销（1.9）

- 弹出层跟着触发按钮滚动；按钮滚出它所在的滚动区就关闭。缩放原点在按钮那一角（`top right` 等）；向上弹出时从下沿长出来。
- 提示条悬停或焦点在里面时暂停倒计时，离开后走完剩下的时间；首页删除的真正清除跟着一起暂停。
- 撤销提示有作用范围：首页删除只在首页按 U 生效（进了比较页仍显示、按钮可点）；批量决定、沿用上轮只对同一对文件，做了下一步（单步决定、写备注、交换、换文件）就收起。
- 审阅连按：220ms 的跳转停顿里再按键，先完成跳转再作用到下一处。

### 长列表（1.8）

- 富文本和纯文本都只挂视口附近的段落，其余用量过的高度占位；选中文字时两端之间全部挂上，全选时挂载全文。

### 查找栏（组件 FindBar，1.9.1）

- Ctrl / ⌘ + F 打开，浮在画布右上角；只搜当前模式里两侧的文档文字，按阅读顺序先左后右、从上到下。
- 匹配用 Bee 浅底，当前这个用 Bee 实色，和差异的红、绿、蓝、紫都不冲突。没有匹配时输入框和“没有找到”用 Cardinal。
- 焦点在输入框里时 A / R / H 等审阅快捷键不响应；Esc 关闭。图像、文件详情模式里没有查找。

### 文件片菜单（组件 FileChipMenu，1.9.1）

- 点文件片弹出小菜单（靠左对齐、向下）：「换一个文件…」「存为往来稿」。粘贴文字（没有文件路径）的比较只有前一项；往来稿的工具栏是版本片，没有文件片。
- 把文件拖到文件片上仍是直接替换，不经过菜单。

### 版本链：起名、删除（1.9.1）

- 每一行悬停或键盘聚焦时，右侧的进度换成「…」；菜单里「起名…」「删除这一版」。起名时这一行变成 Macaw 边框的输入框，下面一行小字写“回车保存 · Esc 取消 · 清空就只显示文件名”。
- 有名称时这一行写“V3 对方 名称”，没名称时写文件名；工具栏版本片始终只写编号，名称在悬停提示里。
- 删除后重新编号，撤销提示写“已删除 V3，后面的版本已重新编号”；只剩两版时删除项置灰，悬停说明原因。
- 「换个比较」用两个 Select S，选项和版本链同一写法：V 编号（我方 Macaw、对方 Fox，900）+ 我方 / 对方（12/800 text-2）+ 名称；收起时名称放不下就省略，悬停提示写全名。菜单浮在弹出层上面，不把弹出层撑高（1.9.4，Figma G1）。

### 表单控件（1.9.4，Figma G1–G3）

**不用浏览器的原生控件。** `<select>`、`<input type=range / checkbox / radio / number>` 的样子由系统决定（展开的菜单、滑块、勾选框跟着 macOS / Windows 变），和 DocDiff 不是一套。界面里一律用下面的组件；原生元素只能出现在这些组件的实现里，并且外观全部由组件画。`<details>` 只留在出错页的“技术信息”。

| 组件 | 规格 | 用在 |

| Checkbox 复选框 | 20px、`radius-xs`、2px Swan；选中 Macaw 底 + `macaw-lip` 底边 + 白勾；文字在右侧 10px，整行可点 | “勾上后一起生效”的选项（弹窗、表单）；改了立刻生效的设置用 Switch |

- 选中色一律 Macaw；不用 `accent-color` 给系统控件染色。
- 查找栏（FindBar）、改名框（NameField）保留各自组件，但边框、聚焦色和 TextInput 一致。

### 尺寸只有一种（1.9.4，Figma G4）

- 按钮只有 L 48 / M 36 / S 30，没有 28。
- ⓘ（InfoTip）只有一个尺寸：16px wolf 图标、24×24 点击区，不跟着旁边的字号变。
- 文件类型标签只有 20 高。
- 视觉小于 24 的按钮（关键词的 ×、小图标按钮）都用透明扩展区补足 24×24。

### 审阅栏与设置页（1.9.8）

- **审阅栏**（组件 ReviewBar）：编号圆 + 位置 + 差异摘录（和纸面同一写法：墨色字 + 文中高亮 + 线型）+ 备注输入框（TextInput S 30，可选，写进 Word 批注，键帽 N）+ 拒绝 / 待议 / 接受三个 Button M 36，键帽跟在文字后。以前写的“三个小按钮”以 1.9.7 实际为准改为 M 36。
- **设置页**：每页以区块标题开头；选项之间不画线，选项间距 16、区块间距 32；说明文字最多一行，其余进 ⓘ（风险页、导出弹窗同样）。名单编辑（我方成员、关键词）是胶囊 + TextInput M 36 + Button M 36「添加」，同一行同高。
- **画布区块标题右侧的显示开关**（只看有变化的段落 / 行）：Switch S + 13/800 text-2。

### 文件名规则编辑器（1.9.9）

- 组件 NameField / NameTag。标签可以拖动换位置：按住移动 4px 才拖起；拖起的标签跟手、带 shade 投影和 Macaw 描边，原位置 35% 透明；落点是 2px Macaw 插入线，只出现在两个标签之间或文字的字与字之间；Esc 取消。键盘：焦点在标签上按 Alt+← / →，越过相邻一个标签。
- 「插入」区的按钮可以拖进框里，样子同上；点一下仍插在光标处。
- 标签之间的文字框按实际字宽量宽度，不按字符数估算。

### 快捷键（1.9.3）

- 有快捷键的按钮，悬停提示统一写成「名称 · 快捷键」（如「交换左右 · ⇧⌘S」，模式按钮第二行写说明）；没有快捷键的只写名称。悬停提示是系统提示框，不画按键样式。
- 按 `?`（首页、比较页都可以；输入框里不触发）弹出快捷键速查（组件 KeysModal），和 设置 · 快捷键 同一张表，两栏、Kbd 样式；设置里那一页顶部写“随时按 ? 打开这张表”。

### 格式变化太密（1.9.3）

- 不改比较逻辑。只在富文本、修订审阅里：格式变化 ≥ 10 处、占全部差异一半以上时，变更列表顶部出现提示「N 处是格式变化」；其中 6 成以上是同一类整段字体（字号）变化时说“多数是整段字体（字号）不同”。
- 「只看文字修改」= 关掉「检测格式变化」；提示变成一行「已隐藏 N 处格式变化 · 恢复」。只对这一对文件，换文件后格式检测恢复、重新判断；点过「恢复」或手动打开过格式检测的那一对文件不再提示。

### 模板 / 往来稿演示（1.9.3）

- 模板 / 往来稿的空卡片里「看看怎么用（30 秒）」，有内容后标题旁的播放图标按钮；不自动弹出（组件 DemoDialog）。
- 用真实界面样式演出来：弹窗里是缩小的 DocDiff 画面，模拟光标（`dur-demo-move`）、点击波纹（`dur-flash`）、镜头推近（`dur-demo-camera`），每步一句字幕；中英文、深色模式跟着应用。
- 每步约 8 秒，底部步骤点可点，可暂停 / 重播。“减少动态效果”时不自动播放、没有光标和镜头，一步一张静态画面（这一步的最后状态），点步骤点切换。
- 模板 3 步：新建模板 → 只拖进对方的文件 → 自动认出模板并比较。往来稿 4 步：存为往来稿 → 加入新版本 → 版本链里选任意两版 → 「上轮」提示和条款历史。文件名、内容都是虚构示例。

## 审阅稿、定稿与完成页

### 审阅稿与定稿（1.8）

- **手动开始。** 做决定只记在 DocDiff 里；点「生成审阅稿」（工具栏 Outline Blue M，或完成页主按钮）才写文件。开始后这一对文件自动同步；往来稿的新一轮再点一次。
- **只属于修订审阅。** 富文本、纯文本等模式不显示、不检查、不写盘。
- **状态只看“写好了没有”。** Word 打开着但决定都写进去了，仍是绿点；只有还有决定没写进去、或有处写不进时才变黄 / 红。
- **只有真的写好了，才说“要发给对方的就是这份”。** 被 Word 占着、写不进去、还没开始，完成页各有说法，不暗示可以发送。
- **定稿是谈完后的干净版。** 有待议时生成定稿降为文字按钮“谈完后：生成定稿…”；弹窗里待议和没决定的处分开说。
- **只响应这一次点击。** 换了文件或开始新的一轮后，不重放之前的请求。

### 完成页（1.8 / 1.9.1）

- 品牌时刻：标题 32/900、DoneStat、彩纸只在第一次出现。
- 打开文件不离开完成页：“打开审阅稿”“在文件夹中显示”、生成定稿后都留在完成页；只有“回去再看看”或 Esc 回到审阅。
- 文件单独一行（FileRow，中间省略）；定稿用 DoneFinal，长文件名不撑出卡片。
- 有待议时副标题写“已看完 N 处修订，M 处待议”。
- 还没生成审阅稿时只留一行状态“结论已保存在 DocDiff 里 ⓘ”，原来的说明框收进 ⓘ。

### 对方 Word 里的结构性修订（1.9）

对方修订删除的整行、被删的段落标记按“接受全部修订”处理：整行不存在（表格空了连表一起去掉）；段落标记被删时本段并入下一段，没有内容就整段去掉，不跨单元格合并。读文件和写审阅稿共用同一条规则（`trackedStructure.ts`）。

### 审阅稿没写完（1.9.2，Figma F10）

- 有决定还没写进审阅稿时，状态片显示“保存中”，不显示“已保存”；完成页、导出弹窗都不把它当成“可以发给对方”的文件。
- 离开界面后照样写完；只有写不进去（Word 占用、被改过、移走、文件夹写不进、出错）时才弹窗，正常情况不打扰。
- 弹窗沿用带对对的弹窗标题（36px，think）、文件行、按钮；每份审阅稿一行：文件行 + “N 个决定没写进去 · 原因”，原因用状态片同一套说法。正文第一句加粗（“不要把它发给对方”），第二句是 13px 次要说明（怎么补）。
- 退出时最多等 5 秒写完；写不完才问“仍然退出 / 先不退出”。主按钮是“先不退出”（有风险的选项不用绿色）；关闭按钮和 Esc = 先不退出。
- 写不进去的审阅稿记为“待补写”：重启弹一次“上次有决定没写进审阅稿”；再打开这次比较时自动补写（状态片“保存中”，弹出层写“上次离开时有 N 个决定没写进去，正在补写…”），写好后记录清掉。
- 启动时这张弹窗底部有复选框「以后启动时不再提示」（Checkbox，默认不勾；1.9.4，Figma G6）。勾上后关掉弹窗（「知道了」、×、Esc 都算），这几份审阅稿以后启动时不再弹；新的待补写照常提示。1.9.5 起只在没写进去的决定数没变多时保持安静：数字变多（又有新的决定没写进去）就当作新情况，启动时重新提示。只是不再提示，记录还在：再打开这次比较时仍自动补写，补写成功后清掉；审阅稿被移走或删掉时，从状态片重新生成。离开后后台写不进去、退出前写不完这两张不加这个选项。

### 批注（1.9.5，Figma H1–H7）

读两份 Word 文件里已有的批注（含回复、“已解决”）。只读，不参与差异匹配；只在富文本、修订审阅里显示，纯文本、图像、OCR 不显示。

- **身份色，不用差异色。** 我方 Macaw、对方 Fox，和往来稿版本编号同一套；对方稿里我方成员写的批注是「我方 · 内部」（Bee 字 + 提醒图标）。批注不用四种差异色，也不用留意黄。
- **谁是我方。** 作者和审阅人、设置 · 审阅 ·「我方成员」名单里的名字一样（不分空格大小写）算我方，其他算对方；名单只在本机。单条批注可以在卡片里改归属（只影响这一对文件）。没署名的算对方。
- **纸面（CommentMark、CommentPin）。** 被批注的文字下面 2px Wolf 点线（用下边框，和删除线、下划线叠在一起都看得清），悬停 / 打开时 hover 浅底。纸边每段一个批注标，数字是条数，颜色按作者（有对方的就是对方）；打开时浅底。富文本两栏各画各的（我方稿的批注在左栏）；修订审阅只有一张纸，我方稿的批注画在修改后文档的同样文字上，文字被改过就挂到对应修订上。修订审阅里，被批注的文字被修订换掉时，换回来的原文、被删掉的字（删除线）也画点线；整段按决定去掉时原位置留一行占位：虚线框、高 30、radius-s、内边距 4 / 12，13/700 text-2，不用斜体，写“这一段按你的决定已去掉，批注还在”，点它等于点批注标（1.9.8，Figma H8），批注标照常挂着；两份文字一样、只有批注时照常显示纸面，顶部 info 提示一行。
- **卡片（CommentCard）。** 点批注标、点线文字、检查器里的行打开；无标题 Popover 样式，宽 340，同一时间只开一张（同一段几条依次列出）。标题下面一行「批注的文字」+ CommentMark（一行，放不下省略；落在被删的字上时写被删的字并加删除线）。一条批注 + 它的回复一张卡片：回复缩进 16、左边 2px Swan 竖线；我的回复是 Macaw 竖线。对方已解决的默认收起。只能回复对方稿里对方的批注，回复生成审阅稿时写成 Word 里同一条批注下的回复，不标“已解决”。批注落在被删的文字上、批注来自我方稿时，卡片里多一行说明。
- **检查器「批注 N」。** 是一个筛选片，0 不显示；N = 对方没解决的 + 我方全部。分组（SectionHeader · Group，无图标）：同事批过、被对方改了 → 对方批注（未回复在前）→ 对方已解决 N 条（收起）→ 我方批注 → 没有修订的地方。行 = AuthorTag + 作者 + “条款 · 状态”，下面一行被批注的文字（CommentMark 12px），正文最多两行，正文被截断时才有悬停提示，选中态和差异行一样。「全部」里，有批注的差异行尾多一个小批注标。
- **审阅栏。** 审到某处修订时，第二行提一条最相关的批注（同事批过被改了 > 对方未回复 > 对方已回复 > 我方），「查看」「回复」；审完最后一处还有没打开过的“没有修订的地方”的批注时提“还有 N 条批注不在修订上”。批注不计入审阅进度。
- **发出去之前。** 完成页写“对方有 N 条批注还没回复”（info，「去看看」= 检查器切到「批注」），只提醒不拦。审阅稿里有我方内部批注时，画布顶部和完成页用 warn 提示，「不带入…」弹窗确认一次（Checkbox 列出每条，默认全勾，主按钮蓝色）；「保留」后这一对文件不再提示。
- **导出。** 定稿去掉全部批注，生成前在弹窗里写明去掉几条（对方 / 我方）；审阅记录存档保留全部批注和回复；比对报告附批注清单，内部批注单独一节。重新排版的修订稿只写你的决定和备注。

## 走查与流程

“浑然一体”靠流程保证。

### 规则

- **单一来源。** 颜色、字号、间距、圆角、阴影、时长只在 `tokens.json` 定义一次；`renderer/src/styles.css` 顶部由它生成。新增 token 要过设计评审。
- **组件只有一个实现。** 行、筛选片、区块标题、弹出层各只有一份代码。新功能先用已有组件组合，组合不出来再提新组件。
- **截图矩阵。** 每次发版截 6 个界面（首页、比较中、结果页、审阅、完成、设置）× 浅色 / 深色 × 中文 / 英文 × 宽 / 窄，共 48 张，和上一版并排比对；任何没预期的变化都要说明。
- **预算检查。** 脚本统计每屏的立体底边、饱和色块、带边框元素和字体样式数量，超出“交互与品牌”里的预算就不能合并。
- **变量和控件检查（1.9.4）。** `check-tokens-usage`、`check-native-controls`、`audit-ds` 三个脚本都过了才能发版；截图矩阵另外截“下拉展开、输入框聚焦、复选框选中、滑块拖动”四张，因为这些状态静态截图看不到。

### 上线前清单

1. 三栏内容从同一条线开始，56 和 96 两条线上没有错位。
2. 每个功能都在“布局”归属表里的位置。
3. 平面内部没有多余的边框，分组靠分组标题和间距。
4. 同一级标题结构一致；区块标题和分组标题没有图标。
5. 能点的有立体底边，不能点的没有；结果页最多一个实心绿。
6. 颜色没有兼职：黄色只表示需要留意，差异色只出现在差异上。
7. 字号、字重、间距、圆角都来自 token；字重只有 400 / 700 / 800 / 900。
8. 用词都在术语表里，没有“变更”“改动”。
9. 检查器和纸面的悬停、点选、筛选双向一致。
10. 每个操作 100ms 内有回应，并且能用键盘完成。
11. 空状态有“对对”、一句话和一个操作；报错说清楚怎么了、怎么办。
12. 两侧栏收起 / 展开后布局不跳动，快捷键和状态记忆有效。
13. 深色模式、英文界面、窄窗口各看过一遍，没有文字被截断；用一对开头相同、结尾不同的长文件名看过工具栏。
14. macOS 红绿灯、Windows 标题栏按钮不压任何内容：侧栏展开、收起、全屏三种状态各看一遍（截图时模拟窗口按钮的位置）。
15. 会改掉多处结论或删除数据的操作都先确认、写清数量；批量改结论做完能撤销。
16. 模拟磁盘写不进去时，界面出现保存警告和“未保存”；恢复后自动补存；任何数据都没有被静默删除。
17. 图像、OCR 用一份 300 页以上的文件看过：先出现范围确认；只比一段时画布顶部写明范围；页码按原文件。
18. 界面里没有系统原生控件：每个下拉展开一次、每个输入框聚焦一次，看到的都是组件库里的样子（1.9.4）。
19. 同一种组件只有一种样子：选中态、焦点框、按钮 / 输入框高度、ⓘ、开关和标签尺寸都对得上组件库（1.9.4）。
20. 批注只用身份色（我方 Macaw、对方 Fox、内部 Bee），没有借用差异色和留意黄；有批注的文件在富文本、修订审阅、检查器里各看一遍（1.9.5）。
21. 类型标签只用 TypeBadge（首页放置区的大文件图标除外）；英文设置页签不折行；check-en 不放过 difference(s)（1.9.8）。
