# DocDiff 组件标准 v1.0

自 1.6.1 起生效。新组件先套用这里已有的组件；套不上，先扩展这份标准，再写代码。代码里的 token 都定义在 `renderer/src/styles.css` 顶部。

## 四条原则

1. **一种颜色只说一件事。** 删除、新增、格式、移动、待议各用一个颜色，不复用。品牌绿只用于操作和品牌，不出现在差异里。
2. **正文是图例。** 地图、概览、列表里的颜色和线型，必须能在文档正文里找到一模一样的样子。
3. **一个零件，一种写法。** 标签、提示条、面板各只有一个组件。
4. **右栏由人来排。** 每块都能收起，状态会记住；看文档时信息越少越好。

## 颜色

| 语义 | 实色（色条、刻度） | 墨色 / 底色（文字、标签） | 线型 |
|---|---|---|---|
| 删除 | `--d-del-solid` #d6402e | `--d-del` #b3261e / `--d-del-bg` #fdebe8 | 删除线 |
| 新增 | `--d-ins-solid` #0f9a74 | `--d-ins` #0b7558 / `--d-ins-bg` #e1f5ee | 下划线 |
| 修改 | `--d-mod-bar`（左红右绿） | 不单独配色 | 删除线 + 下划线 |
| 格式 | `--d-fmt-solid` #3070d8 | `--d-fmt` #2459a8 / `--d-fmt-bg` #e7eefb | 虚线下划线 |
| 移动 | `--d-move-solid` #b03ea9 | `--d-move` #8a2f86 / `--d-move-bg` #f6e8f5 | 双线 |
| 待议 / 需要留意 | `--warn` | `--d-hold` #7a5600 / `--d-hold-bg` #fff3cf | 无，配图标 |

- 深色模式各有一套（删除 #e45a46 / #ff9c8a / #3b201c 等），文字对比度都在 7:1 以上。
- 浅色实色通过色彩校验（色弱最小差 9.1，正常视力最小差 19.3）；深色在色弱下为 7.4，依靠线型补足。
- 界面色分工：品牌绿 = 主按钮、选中、开关、进度；蓝 = 链接、焦点框；琥珀 = 待议、需要留意、警告；红 = 删除、出错、危险操作；中性色偏绿灰。

## 字号与字重

`--fs-11` 角标 · `--fs-12` 说明、标签 · `--fs-13` 右栏正文、列表 · `--fs-14` 界面默认 · `--fs-16` 弹窗标题 · `--fs-20` 页面标题 · `--fs-28` 首页大标题。

字重 400 正文，700 标题和强调；800 只留给首页和品牌字样。文档正文（纸张里的内容）跟随原文件，不受限制。

## 间距、圆角、层次

- 间距用 4 的倍数：组件内部 4 / 8 / 12，组件之间 8 / 16，区块之间 24 / 32。
- 圆角 4 档：`--r-s` 6（小件、标签）、`--r-m` 10（控件、面板）、`--r-l` 14（卡片、弹窗）、全圆（开关）。
- 层次三层：底（窗口）→ 面（面板，1px 边框，无阴影）→ 浮（弹窗、菜单、提示，`--shadow-float`）。

## 组件

### 右栏面板 `Panel`

- 标题栏 40px：折叠箭头 + 图标（可选）+ 名称 + 计数，整行可点；右侧最多一个面板自己的操作，加“只看这一块”。
- 可同时展开多块；状态存 `localStorage['panels-v1']`。默认折叠 `scope`、`settings`。
- `grow` 面板（变更列表、页面）吃满剩余高度，最小 200px；其余面板按内容高，超过 40vh 内部滚动。
- “只看这一块”：其他面板隐藏，顶部显示“只看：xx · 显示全部”；Esc 恢复。

### 差异概览 `Overview`

五格：数字（16/700）+ 名称（11），左侧 3px 色条，与变更列表行的色条是同一种元素。点一下只看这一类；选中格边框为标题色，其他格 50% 不透明。数量为 0 显示 0 且不可点。

### 变更列表行

最小高 32px：左侧 4px 色条（类别）+ 单行摘要（省略号，完整内容在悬停提示）+ 最多一个标签（审阅结论优先，其次需要留意）。当前项：次级底色 + 色条加宽到 6px。富文本、纯文本、OCR 共用。

### 差异地图 `ChangeMap`

宽 14px。刻度高 3px；修改为左红右绿各半。可见区域只画 2px 描边。当前项左侧小三角。筛选时其他类别 25% 不透明。超过 200 处画密度条：每段取数量最多的类别，深浅三档（40% / 70% / 100%）。

### 纯文本差异行

左侧 3px 色条；改动的词用高亮底 + 线型。只有整行新增或删除时整行铺浅底色。

### 标签 `.tag`

色调：中性（默认）· `brand` · `del` · `ins` · `fmt` · `move` · `hold` · `mod`（中性 + 双色小条）。样式：实底 / `outline`。尺寸：20px（默认）/ `sm` 16px / `lg` 28px（带关闭按钮的筛选）。可点的标签必须是按钮。

### 提示条 `Notice`

色调 `info` / `warn` / `err` / `ok`。结构：图标 + 粗体一句话（发生了什么）+ 补充 + 最多一个操作 + 可选关闭。位置变体：`bar`（文档上方通栏）、`in-main`（文档区内）、`in-panel`、`stack`（弹窗、卡片内）。

### 按钮 `.btn`

主要（`primary`，品牌绿 + 2px 底边，每屏最多一个）· 次要（默认，描边）· 文字（`plain`）· 危险（`danger`，红字描边）。高度 `big` 40 / 默认 32 / `sm` 28。审阅栏的拒绝 / 待议 / 接受（`red` / `hold` / `primary`）是三选一的决定按钮，也带底边。小图标按钮用 `.icon-btn`（28px），行内文字操作用 `.link-btn`。

### 表单控件

开关、分段控件、下拉、输入框统一 32px 高、圆角 10；焦点为 2px 蓝框。

## 文字与动效

- 按钮写动作（“导出”“标为待议”），不写“确定”。数字后跟单位或名词。面板标题用名词，2–6 个字。提示条先说发生了什么，再给一个操作。
- 展开、折叠、悬停 150ms 缓出；跳到差异时滚动加一次闪烁；系统设置“减少动态效果”时全部关闭；结果页不放装饰动画。
