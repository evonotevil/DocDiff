# DocDiff 1.8（1.8.0）

1.8 正式版。相对 1.7.5，新增了审阅稿、定稿、模板和往来稿，重新排布了首页和设置。你现在的设置和审阅结论会原样保留。

## 安装

- **macOS**：解压 `DocDiff-1.8.0-mac-arm64.zip`（Apple 芯片）或 `…-mac-x64.zip`（Intel），把 DocDiff 拖进「应用程序」替换旧版。
  - 也可以运行「制作DMG.command」做成 DMG。
  - 第一次打开如果被拦，在「系统设置 → 隐私与安全性」里点「仍要打开」。
- **Windows**：运行 `DocDiff-Setup-1.8.0.exe`，覆盖安装。

## 新功能

### 审阅稿：决定写进 Word，发回给对方

- 在修订审阅里点「生成审阅稿」，会在对方文件旁边生成一份 Word 审阅稿。
  - 对方原文件不动。
  - 接受的直接采用；拒绝的以你的名义改回原文（Word 修订）。
  - 未决定和待议的保留为对方的修订；待议和备注写成批注。
- 开始之后，这一对文件的每个决定约 0.3 秒内自动写入。往来稿的新一轮要再点一次。
- 审阅稿只在修订审阅里生成和同步；富文本、纯文本等模式只做比较。
- 不会弄坏文件：
  - 审阅稿在 Word 里打开着、又有新决定时，先暂停，关掉 Word 后自动补写。
  - 在 DocDiff 之外被改过时，停下来不覆盖，可以另存一份。
  - 页眉页脚、文本框等写不进去的处会逐条列出。
- 审阅稿被删或挪走时，按设置自动重建（按 DocDiff 里的决定，Word 里直接改的内容不保留），或者先问你。

### 定稿

- 双方谈完后，生成一份干净的 Word：没有修订标记和批注。
- 待议和没决定的处，可以选择「保留对方的改动」或「恢复原始文档」，并写明原始文档是哪一份。
- 有写不进去的处，先列出来，你确认后才保存。
- 没开始审阅稿也能生成定稿。

### 完成页

- 只有审阅稿真的写好了，才说「要发给对方的就是这份」。
  - Word 开着而且还有决定没写进去：提示先关掉 Word。
  - 有写不进去的处：逐条列出，可以直接回到这几处。
- 待议算看完，但会写明「M 处待议」。有待议时，生成定稿放在「谈完后」。
- 打开审阅稿、生成定稿之后，都会回到完成页。

### 模板

- 把标准合同存成模板，可以上传新版本。
- 对方改稿来了只放对方的文件：DocDiff 会认出是哪份模板、对方在哪一版上改的。

### 往来稿

- 一份合同来回改好几轮时，每一版都留着。
- 下次只放对方的新稿，默认和上一版比；上一轮的结论作为参考显示，也可以沿用。

### 首页和设置

- **首页**：
  - 第一次用时有完整引导。
  - 有了往来稿、模板或最近比较后，改成紧凑布局：放文件的区域变矮，往来稿和最近比较在首屏完整露出。
- **最近比较**：
  - 两份文件共同的名字只写一次，下面写清两边不同的部分（如「V1 → V3」）。
  - 属于往来稿的一对，直接写往来稿名。
  - 状态放在右侧固定一列。
- **设置**：分成通用、审阅、审阅稿与定稿、风险、快捷键、存储、关于与更新，每页一屏放下。较长的说明放在「ⓘ」悬停里。

## 改进与修复（相对 1.7.5）

- **纯文本视图按需挂载**：约 3000 段的文档，切换到纯文本的中位耗时从约 600 ms 降到约 250 ms，画布节点从约 2.7 万降到约 1.1 千。
- **快捷键和菜单**：弹窗或弹出层开着时，键盘快捷键和菜单栏快捷键都不作用到后台。
- **「…」菜单**：
  - 在窗口下方时，紧贴按钮向上弹出。
  - 样式统一。
- **审阅结论的保存**：主文件只在确认完好时才轮换备份。

## 相对 1.8.0-beta.7 的修改

- **点「打开审阅稿」或「在文件夹中显示」后，完成页留着**：不再跳回最后一处。
- **Word 打开着审阅稿、但决定都已写进去时，不再当成「没写完」**：工具栏保持绿色，弹出层里说明 Word 正在打开它。
- **「定稿已生成」改成三行**：标题、文件（中间省略）、按钮。长文件名不再撑出完成页；回到完成页时不再重复弹出同样的提示。
- **往来稿加入新版本、或换成新的一对文件后，不再自动弹出「生成定稿」**：上一轮点过的请求不再被重复执行。
- **最近比较按新设计重排**：见上。
