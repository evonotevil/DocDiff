# 设计系统走查（1.9.3 现状，2026-11-09，只记录，未修改）

**方法**
- 读代码：`renderer/src` 里的原生控件、`styles.css` 里写死的颜色、间距、高度和未定义的变量。
- 跑应用：`scripts/audit-ds-194.cjs` 用合成夹具（Document A / B）走一遍首页、设置 7 页、粘贴、比较页 5 种模式、导出、文件片菜单、比较设置、PDF 图像淡化。每屏截图，并记录 663 个可交互元素的计算样式。截图在 `work/audit-194/`。
- 对照：`design-standard.md` 4.0 和 Figma 组件页（54 个组件）、图标页。

**结论**：问题集中在三处。
1. 表单控件没有进设计系统，代码里直接用浏览器原生控件。
2. 同一种组件有多套写法。
3. 自动检查只管字号、圆角、时长，所以颜色、间距、高度、原生控件可以一直漏过去。这也是同类问题反复出现的原因。

## D. 组件库（Figma）缺的

- **代码里有、Figma 没有的界面块**：往来稿版本链弹出层（版本行、比较过的行、换个比较）、设置左侧页签、导出弹窗的选项卡片（单选卡）、关键词标签、图像模式工具（淡化滑块、缩放）、粘贴弹窗。
- **图标**：代码有 47 个，Figma 图标页缺 13 个：Minus、Plus、File、Format、Move、Clock、ChevronLeft / Right、Focus / Unfocus、Play / Pause / Replay。Figma 里 `icon/edit` 重复 2 个、`icon/search` 重复 3 个。

## F. 为什么一再出现

- `check-tokens-usage.mjs` 只查字号、圆角、时长。颜色、间距、控件高度、原生控件、未定义变量都不查，所以新写的界面可以自己写一套。
- 组件库里没有 Select / Input / Checkbox / Slider，新功能只能临时写。
- 截图矩阵只看静态画面，下拉展开、滑块这类系统控件的样子截不到。

## 建议（待对齐）

1. 先补组件，再替换：Figma 出 Select、TextInput（含数字、多行）、Checkbox、Slider，以及版本链弹出层的整页稿。代码各一个实现，替换 A1–A6 和 B1。
2. 统一状态：焦点框 3px、竖向导航选中态统一、InfoTip 固定字号、按钮去掉 28、开关和标签各定一个尺寸。
3. 收口变量：间距并到刻度上（6 → 4 或 8，10 → 8 或 12，20 → 16 或 24，逐处看）、控件高度用变量、颜色进 token、删掉 `--r-*` 旧名、修 `--space-5`。
4. 补检查：扩展 `check-tokens-usage.mjs` 到颜色、间距、高度、未定义变量；新增“不允许原生 select / range / checkbox / number”的检查；走查脚本 `audit-ds-194.cjs` 进发版流程。
5. 规范：删掉第 85 行旧规则；组件清单补上新组件；Figma 图标补齐、去重。
