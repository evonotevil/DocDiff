# DocDiff 1.9.3

设置、审阅结论、往来稿和模板都原样保留，比较结果不变。界面先在 Figma 里确认过（「方案 · 1.9.2–1.9.3」F9b、F11–F14），设计规范升到 4.0。

## 首页更清爽

- 三个模块改成白色卡片，去掉灰色标题条和蓝 / 紫 / 橙三个彩色图标块；标题前换成小插画（新比较、往来稿、模板各一张），三个模块不再靠颜色区分。
- 「最近比较 | 往来稿」页签：选中的是蓝色文字加下划线，条数是灰色文字。
- 卡片本身不再变色、不再跳动；鼠标移到里面的行上时，这一行变浅灰。
- 卡片空着时，显示一张插画、一句话和下一步怎么做。

## 第一次用的首页

- 和用过之后是同一个样子：新比较在上，下面是「最近比较 | 往来稿」和「模板」两张卡片。原来的大标题和底下那行说明去掉了，“全部在这台电脑上完成，不会上传”写在新比较标题旁边。

## 模板和往来稿：30 秒看懂怎么用

- 模板、往来稿卡片空着时，点「看看怎么用（30 秒）」，在弹窗里用 DocDiff 的界面演一遍：光标、点击、镜头推近，每一步一句说明。
  - 模板：新建模板 → 只拖进对方的文件 → 自动认出模板并开始比较。
  - 往来稿：存为往来稿 → 加入新版本 → 在版本链里选任意两版 → 新一轮里看到「上轮」提示和条款历史。
- 底部的小圆点可以跳到某一步，也可以暂停、重播。卡片有内容后，标题旁的播放图标还能再看。
- 打开了“减少动态效果”时不自动播放，一步一张画面，点小圆点切换。中英文、深色模式都跟着应用。

## 快捷键更好找

- 鼠标停在有快捷键的按钮上，提示里直接写出快捷键，比如「交换左右 · ⇧⌘S」「下一处 · J」「拒绝 · R」。
- 随时按 **?** 打开快捷键速查（首页、比较页都可以；在输入框里打 ? 不会弹出）。

## 格式变化太多时，一键只看文字修改

- 两份 Word 一份是另存或转换出来的、整段字体字号都不同时，变更列表顶部会提示「N 处是格式变化，多数是整段字体不同」，点「只看文字修改」就只剩真正的文字修改；想看回格式，点「恢复」。只对这一对文件生效，换文件后重新判断。

## 设计规范 4.0

- 规范按话题重排：以前每个版本追加在文末的规则，都并回颜色、布局、文字、交互、审阅稿等对应章节，规则内容不变。组件库补上了新的插画、空卡片、快捷键速查和演示弹窗。
