# DocDiff 1.7.3

修复评审发现的五个问题，重点是“比较结果覆盖全文”和“审阅结论不会悄悄丢”。覆盖安装即可：第一次打开时，旧版存下的设置和审阅结论会自动搬到新的保存位置。

## 安装

- **macOS**：打开 `DocDiff-1.7.3-mac-arm64.dmg`（Apple 芯片）或 `DocDiff-1.7.3-mac-x64.dmg`（Intel），把 DocDiff 拖到“应用程序”里替换旧版即可。
- **Windows**：运行 `DocDiff-Setup-1.7.3.exe`，按提示覆盖安装。

## 图像 / OCR 不再只比前 300 页

- **以前**：图像和 OCR 模式会把整份文档一次渲染成图片放在内存里，为了不撑爆内存，只取前 300 页。界面上的“第 i/n 页”却写的是总页数，也不提示后面的页没有比较；文字模式又比较全文，两边的范围对不上。
- **现在**：改成逐页渲染。每次只渲染一对页面，比完就压缩成图片、释放画布，内存不再随页数增长（452 页实测渲染进程 JS 堆约 80 MB），也就不再需要上限。
- 两份文档里任何一份超过 300 页时，图像和 OCR 开始前先告诉你两份各有多少页、预计要多久，你可以选择比较全部，也可以只比较一段页码，比如第 301–330 页。
- 只比较了一段时，页面上方和 OCR 的识别质量旁边都会写明“只比较了第 a–b 页，共 n 页；其余页面没有比较”，点“更改”可以重新选择范围。页码一律按原文件的实际页码显示。
- 文字模式（富文本、纯文本、修订审阅）一直比较全文，不受这个范围影响。
- OCR 改成每 6 页送去识别一次，进度、取消都照常。

## 全部接受 / 全部拒绝 / 重置要先确认，做完可以撤销

- 三个菜单项改成“全部接受…”“全部拒绝…”“重置所有决定…”，点了先弹出确认，写清会覆盖几个已有结论、几处本来就是这个结论、几处还没决定；重置时写清会清空几个结论，备注保留。
- 执行后底部出现提示，10 秒内点“撤销”或按 U，所有结论恢复到操作前，连同保存在本机的记录。

## 审阅结论可靠保存

- **以前**：结论存在窗口自带的浏览器存储里。超过 120 组比较会悄悄删掉最旧的；存不进去（空间满了、被系统拦截）时也不提示，界面照样显示“已接受”，重启后才发现没了。
- **现在**：每组比较的结论存成应用数据目录里的一个文件（Mac：`~/Library/Application Support/DocDiff/reviews/`；Windows：`%APPDATA%\DocDiff\reviews\`）。写入时先写临时文件再替换，并保留上一份备份；主文件损坏时自动用备份。
- 不再自动删除旧记录。“设置 → 审阅”里能看到保存了多少组、占多大空间，可以手动“清理 90 天前的记录”或“全部清空”，两个操作都要再确认一次。
- 存不进去时，结果页顶部出现警告“审阅结论没能保存到本机”，审阅栏标“未保存”，并给出“重试保存”；下一次保存成功后警告自动消失。
- 偏好设置、主题、语言、最近比较也改用同样的写法，存不进去时同样会提示。
- 第一次打开 1.7.3 时自动把旧版的设置和审阅结论搬过来，搬成功后才删除旧数据。

## 其他

- “最近比较”每一条右上角的删除按钮恢复常显（v1.4.1 起本来就该常显，后来被改成只在鼠标悬停时出现，键盘会聚焦到看不见的按钮上）。
- 文件名很短时（如“合同_v1.docx”），文件片不再被截成只剩“.docx”。
- README 的“已知限制”改正：批注不参与比较；页眉、页脚、脚注已经参与，但单页 PDF 等场景可能识别不出来。
