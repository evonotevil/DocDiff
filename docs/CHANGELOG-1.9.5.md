# DocDiff 1.9.5

设置、审阅结论、往来稿和模板都原样保留。界面先在 Figma 里确认过（「方案 · 1.9.5 · 批注」H1–H7），设计规范升到 4.2。

## 读出文档里已有的批注

- 两份 Word 文件里已有的批注（含回复、“已解决”）都读出来，只在本机解析。富文本、修订审阅里显示；纯文本、图像、OCR 不显示。
- 纸面：被批注的文字下面有一条灰色点线，纸边每段一个批注标（数字是条数）。橙色是对方的，蓝色是我方的。点批注标或点线文字打开批注卡片，看全文和回复。
- 我方稿里同事的批注也列出来：文字两边一样时，在修订审阅里画在修改后文档的同样文字上；文字被对方改过，就挂到对应修订上，检查器里置顶。
- 批注落在被对方删掉的文字上时，卡片里写明删的是哪句。

## 检查器「批注 N」

- 新的筛选片「批注 N」：N 是对方没解决的加我方的。点开只看批注，按“同事批过、被对方改了 → 对方批注（没回复的在前）→ 对方已解决（收起）→ 我方批注 → 没有修订的地方”分组。
- 点一行：纸面滚到那里，打开那条批注的卡片。
- 「全部」里，有批注的修订行尾多一个小批注标，点它打开卡片，不改当前选中的修订。

## 审阅时看到批注、直接回复

- 审到某处修订，审阅栏第二行提一句这里的批注（同事批过被改了的优先，其次是对方没回复的），可以「查看」「回复」。
- 在卡片里回复对方的批注：生成审阅稿时写成 Word 里那条批注下的回复（Word 和 LibreOffice 里都显示成同一个对话），不标“已解决”。回复可以改、可以删。
- 审完最后一处修订时，如果还有没打开过的、不在修订上的批注，审阅栏会提一句。批注不计入审阅进度。

## 谁是我方

- 设置 · 审阅 新增「我方成员」：批注作者是这些名字时算我方，审阅人自动算在内，其他人算对方。下面列出文件里读到的作者，点名字就加进名单。名单只在本机。
- 个别批注可以在卡片里改归属（这是对方的 / 这是我方的 / 把作者加进我方成员），只影响这一对文件。

## 发出去之前

- 完成页提醒“对方有 N 条批注还没回复”，可以点进去看，不拦着生成审阅稿。
- 对方稿里混着我方同事写的批注（内部批注）时，画布顶部和完成页提醒“审阅稿里有 N 条我方内部批注”。「不带入…」列出每一条，确认后审阅稿里去掉它们（连同它们的回复）；DocDiff 里和存档里仍保留。「保留」后这一对文件不再提示。

## 导出

- 定稿：和以前一样去掉全部批注，生成前在弹窗里写明会去掉几条（对方 / 我方）。
- 审阅记录存档：保留文档里全部批注和回复（每条对话写成一条批注，标明对方 / 我方 / 内部）。
- 比对报告：附批注清单，按条款列出双方的批注和回复；内部批注单独一节。

## 启动提示更准

- 勾了「以后启动时不再提示」以后，只有没写进审阅稿的决定数没变多时才保持安静；又有新的决定没写进去，启动时会重新提示。

## 设计规范 4.2

- 新增「批注」一节；组件库补 AuthorTag、CommentPin、CommentMark、CommentCard，图标库补 comment；上线前清单第 20 条。

## 记录，之后再做

- 无段距分段（段距为 0 时两段被并成一段）。
- PDF 注释、往来稿历史轮次里的批注。
