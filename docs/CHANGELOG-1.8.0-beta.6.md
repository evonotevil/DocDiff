# DocDiff 1.8 测试版 6（1.8.0-beta.6）

在 beta.5 的基础上，按试用反馈修改。

## 改了什么

- **首页对齐**：「往来稿」「模板」两张卡片和上面两个放文件的区域用同一套列宽，左右边缘对齐。
- **审阅稿只属于修订审阅**：
  - 富文本、纯文本、图像等模式只做比较，不显示审阅稿，也不检查、不写盘。
  - 进入修订审阅后，才检查、生成和同步审阅稿。
  - 从修订审阅切到别的模式，正在进行的写入照常完成，只是不显示。
- **以前的审阅稿被删了或挪走了**：在「设置 · 审阅 · 审阅稿」里二选一。
  - 自动重新生成（默认）：再次进入修订审阅时，在原位置重新生成一份，所有决定都写进去，并提示一次。
  - 先问我：显示“审阅稿不见了”，你点“重新生成”才生成。
- **生成定稿**：没决定的处的两个选项改为“保留对方的改动 / 恢复原始文档”。
  - 下面写明原始文档是哪一份：往来稿写版本号；第一版来自模板时，写模板名和版本；普通比较写文件名。
  - 默认仍是保留对方的改动。

## 测试

- 新增 `e2e-beta6.cjs`：
  - 1440 和 1100 宽度下，卡片和放文件区域的左右边缘对齐。
  - 富文本模式不出现审阅稿片，也不写文件。
  - 删掉旧审阅稿后，富文本里不提示；进入修订审阅后，在原位置自动重新生成并提示一次。
  - 改成“先问我”后，只显示“不见了”，不自动生成。
- 之前的单元测试、审阅稿写入 77 项，以及审阅稿、模板、往来稿、beta.4、beta.5 五套端到端测试，全部通过。
