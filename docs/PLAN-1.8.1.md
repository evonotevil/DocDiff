## 决定

- **徽章**：实心加深、白字。
  - DOCX 用 macaw-ink #0c6fa6（5.5:1）。
  - PDF 用 cardinal-ink #c41e1e（5.9:1）。
  - TXT 用 text-2 #6f6f6f（5.0:1）。
  - 深色模式用同样的深色底（白字都 ≥ 4.5:1）。
  - 规范「已知的品牌例外」补一句：类型徽章用墨色底。
- **大屏**：双栏总宽上限约 1738（每栏 ≤ 860 + 间距 18），居中；960–1440 不变；单栏视图仍 860。
- **英文提示**：紧凑放置区的空态提示允许两行，文字不改；放了文件后文件名仍是一行中间省略。
- **交付**：出 1.8.1。范围是 P1、P2 和英文单复数，**字体瘦身也做**；200% 缩放（13）、其余低优先级（16）记录不做。

## 实施顺序

1. **Figma 先出图，确认后改代码**：
   - TypeBadge 新配色（浅色 / 深色）。
   - 宽屏比较页（2560）。
   - 英文紧凑放置区两行。
   - 最近比较的时间、元信息改用 text-2。
   - 同步改规范文档和 tokens。
2. **直接修**：
   - 第 2 项：hare → text-2，并排查其他用 hare 承载可读文字的地方。
   - 第 3 项：「ⓘ」改成 button + aria-describedby。
   - 第 4 项：行容器改普通元素，「打开」由覆盖式按钮承担，「…」独立；Enter / Space 仍能打开。
   - 第 5 / 14 项：首页包 main；老用户首页「新比较」作 h1，视觉不变；比较页加视觉隐藏的 h1。
   - 第 6 项：开关点击区扩到 ≥ 24×24，视觉不变。
   - 第 7 项：`.drops` 改成 `minmax(0,1fr)`，`.drop` 加 `min-width: 0`；「移除」按 Figma 用 S Outline。
   - 第 8 项：段落和单元格加 `dir="auto"`，差异 span 加 `unicode-bidi: isolate`；纯文本 / OCR 同样处理。
   - 第 9 项：语言变化时让比较区重新渲染（按语言重挂，或订阅语言）。
   - 第 12 项：英文用 `Intl.PluralRules` 处理 页 / 段 / 处差异 / 还差 N 个文档。
3. **字体瘦身**：
   - 只保留 woff2，去掉 woff 回退。
   - Noto Sans SC 只保留实际用到的字重，保留按字符范围拆分的子集。
   - 去掉 CSS 里内嵌的 data-URI 字体。
   - 回归：生僻字、中英混排、阿拉伯文、打印 / 导出 PDF、导出报告。
4. **验收**：
   - axe 在首页（两种）、比较页、设置、导出弹窗、浅色 / 深色下，没有 serious / critical。
   - 键盘 Tab 顺序合理，焦点可见，Esc 回焦。
   - 长文件名（含空格、emoji、CJK、无空格长串）在 960 / 1440 / 2560 下不超出。
   - 阿拉伯文、希伯来文、混排方向正确；不刷新中英切换后全部文案跟着切。
   - 2560 下居中、每栏 ≤ 860。
   - 示例合同差异数不变。
   - 现有单元、端到端、界面检查全部通过；`tokens:check` 通过。
   - 字体瘦身前后各量一次包体大小。
