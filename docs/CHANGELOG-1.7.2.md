# DocDiff 1.7.2

修复一个会导致白屏的问题。覆盖安装即可，设置、最近比较和审阅决定都会保留。

## 新建比较后白屏

- **现象**：比较过一次后点“新建比较”，换一组文件再点“开始比较”，整个窗口变成白屏，只剩菜单栏。macOS 和 Windows 都会出现。
- **原因**：新结果算出来之前的一瞬间，界面拿上一次的比较结果去画新文档。上一次的结果是按旧文档的段落编号记的，新文档段落更少时就会读到不存在的段落，整个界面崩溃。前后两组文件段落数差得越多越容易出现（例如先比一份长合同，再比一份短文件或 PDF）。在“文件片”上直接换文件、交换左右时也可能触发。
- **修复**：换了文档后，新结果算出来之前不再使用旧结果。

## 兜底

- 界面万一出错，不再整窗白屏，而是显示“对对”、一句说明和“重新载入”按钮；文件、设置和审阅决定都保存在本机，不会丢。

## 验证

- 5 组不同类型的文件（长 Word、短 Word、TXT、PDF、Word 与 PDF 混比）两两组合，先比一组再新建比较另一组，共 25 种；另外在“修订审阅里做过决定”“筛选过某一类”“看过图像模式”“选中过某一处”四种状态下各再测 9 种。修复前 25 种里有 8 种白屏，修复后全部正常。
