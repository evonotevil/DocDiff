# 1.9.1 方案（已实施，见 `CHANGELOG-1.9.1.md`）

来源：`docs/ISSUES-1.9.md` 的 6 条使用反馈。2026-11-05 逐项对齐。

## 1. 往来稿：删除某一版、给某一版起名

- **删除**：版本链里每一版都可以删除（至少保留两版时才可删；只剩一版时整份往来稿照旧用“删除往来稿”）。
  - 删掉中间一版后**重新编号**：V1–V5 删掉 V3，原来的 V4、V5 变成 V3、V4。
  - 和这一版有关的审阅记录（以它为一侧的那几轮）一起去掉，其余轮次保留；上次打开的比较如果用到它，回到最新两版。
  - 和删除往来稿一样，10 秒内可以撤销。
- **起名**：每一版可以加一个名称，显示为「V3 · 对方第二次修改」。
  - 默认不填，没名称时照旧只显示 V3；编号始终保留，所以「V2 → V3」读起来不变。
  - 在版本链里改名（和模板版本改名同样的交互）；名称只用于显示，不影响文件名。

## 2. 条款编号和 Word 一致

- 章节标题带自动编号时，显示编号（如「10.」），并参与计数。
- 读 `numbering.xml` 的起始值（`w:start`）和重新起编（`w:lvlOverride` / `w:startOverride`）。
- 共用同一个编号定义（`abstractNum`）的列表按 Word 的规则接着数。
- 编号只是显示，不算差异（和现在一样）。
- 回归：合成夹具覆盖“标题带编号 + 多级条款”“从 5 开始”“中途重新起编”“两个列表共用编号定义”，和 Word 的显示逐条对照。

## 3. 查找

- Ctrl / ⌘ + F 在比较页顶部打开一条查找栏：搜当前模式里两侧的文档文字，高亮所有匹配，Enter / ↓ 下一个、Shift + Enter / ↑ 上一个，显示“第 i / n 个”，Esc 关闭。
- 不过滤右侧的变更列表。
- 富文本、纯文本、修订审阅、OCR 文本里可用；图像、文件详情里不显示。

## 4. 弯引号和直引号

- 比较设置里加「忽略引号样式（直引号 / 弯引号）」，**默认开**；词中间的撇号（Company’s）也算。
- 比较范围的“条件”里写明这一条；关掉后恢复现在的行为。
- 格式变化太密（整段字体、字号不同）的问题：本轮只记录，先用合成样本复现，下一轮再定。

## 5. 首页存为往来稿不打开比较

- 首页「最近比较」里选「存为往来稿」：留在首页，这一行显示“正在保存…”，在后台读两份文件、建往来稿。
- 完成后提示「已存为往来稿 X」，这一行出现在「往来稿」里；不打开比较。读不了文件时提示原因，不建往来稿。

## 6. 比较页里存为往来稿

- 工具栏的文件片区域（Document A → Document B）点开有一个小菜单，里面有「存为往来稿」：所有模式都有，不管有没有修订。
- 修订审阅「…」菜单里的入口保留。
- 已经是往来稿、或粘贴文字（没有文件路径）的比较，不显示这一项（和现在一样）。

## 7. 首页：整页不滚动、模块配色（2026-11-06 对齐）

- **高度**：首页整页不滚动。顶栏、新比较、底栏固定；往来稿和模板两张卡片撑满中间剩下的高度，内容多了在卡片里滚动。
- **小窗口**：卡片放不下 3 行（窗口高大约 < 640）时，退回整页滚动，卡片保持 3 行高。
- **最近比较**：左边卡片改成页签「最近比较 | 往来稿」（最近比较在前），各自滚动，页签上显示条数；第一次打开默认最近比较，之后记住上次选的；选中用 Macaw 下划线和计数；“清空”只在最近比较页签里。
- **配色**（2026-11-06 第二次对齐）：只用 26px 图标块的颜色区分模块——新比较 Macaw 蓝、往来稿 Beetle 紫、模板 Fox 橙；标题条统一用侧栏的中性浅底，列表区白色。避开绿（主操作 / 接受 / 成功）和黄（需要留意 / 待议），整页的饱和色只剩品牌绿和这三个小图标。
- **悬停**：鼠标进入某个模块，卡片边框在 150ms 内从 Swan 灰变成模块色，图标块跳一下（4px，300ms）；不位移、不加阴影（卡片本身不能点）。“减少动态效果”时只变边框颜色。
- **对设计系统的影响**：
  - 新增变量 `beetle-lip`、`fox-lip`（图标块底边），写进 `design-tokens.json`。
  - 新组件：模块卡片（中性标题条 + 26px 彩色图标块 + 卡片内滚动区，最少 3 行，悬停态）、下划线式页签（带条数）。
  - 规范补两条：首页整页不滚动；“首页模块色”只用在图标块和悬停边框，只在首页出现（Beetle 在比较页仍是“移动”和“OCR 文本”的颜色，两处不同时出现）。
  - 现有组件（Row、按钮、最近比较行、放置区）不变。
- **第一次用**的首页不变。
