# DocDiff 1.9.8 · 设计系统对齐

对照 Figma「DocDiff 设计规范」组件库，把 1.9.7 里没对齐的地方补齐。规范同步升到 4.3。

## 界面
- 审阅栏：按钮统一用 M 号（36），备注栏保留；规范按此改写。
- 比较范围：检查器底部的「详情」改叫「更改」。
- 设置：去掉选项之间的分隔线；通用、风险页加小标题；风险页说明收成一行，细节放进 ⓘ。英文页签改短名 Redlines / About。
- 导出弹窗：说明收成一行，细节放进 ⓘ。
- 修订审阅里被去掉段落的占位说明行，按 H8 改成虚线框、不再斜体，点它直接打开批注。
- 批注标：展开时改为蓝色描边（对方为橙色），不再换底色；静态批注标高 24。
- 文件行一律用类型徽章（TypeTag），弹出菜单宽度统一 260。
- 开关关闭态底色改用 Swan；文件名标签的 × 点击区扩到 24。
- 去掉中文标签上的字间距；代码对比两栏分隔线改 2px；小标签字重 800、提示里的粗体 700。

## 设计变量
- 新增 swan-strong、doc-muted、doc-rule、doc-ph、doc-hatch、img-chip-bg、img-chip-fg，兼容层不再写死颜色。
- 删除无用样式（.vs-chip、.lib-gh、.tag.lg）和旧 Logo 图标；导出报告的次要文字改用 #6f6f6f / 700。

## 文案
- 提示语去掉「请」，「改动」统一为「修改 / 修订 / 写法」。
- 英文 difference(s) 统一为 change(s)，check-en 加入该检查；新增 dict.en.198.ts。
