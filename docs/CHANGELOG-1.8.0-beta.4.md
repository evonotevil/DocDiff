# DocDiff 1.8 测试版 4（1.8.0-beta.4）

在 beta.3 的基础上，按试用反馈和确认过的设计稿（Figma「方案 · 1.8 正式版 · 界面修订」）修改。

## 改了什么

- **撤销提示**：删除往来稿、模板后的提示改成规范里的单行胶囊。
  - 写成“已删除往来稿「名字」”。名字太长时省略中间，悬停看全名。
  - “撤销 U”和关闭按钮始终完整显示，不再折行。
- **设置 · 审阅**：按规范重排成三块。
  - 审阅人、文件名、审阅记录三块，区块之间留出间距，输入框高 48。
  - 审阅记录改成两行统计，后面一句说明和两个按钮。
- **文件名输入框**：
  - 默认的“我方意见”“定稿”和“-”都可以删，可以随便打字。
  - 插入标签时不再自动加“-”，分隔符由你自己打。
  - 整个框删空也可以：框里用灰字写出默认值，生成时用默认规则。
  - “插入”按钮只在编辑这个框时出现。
  - “预览”和文件名在同一行。
  - 改过的框，标题右侧有“恢复默认”。
- **往来稿版本弹出层**：
  - 可以直接把新版本拖到工具栏的版本片或弹出层上：弹出层会自动打开，整块变成放置区；松手后打开「加入新版本」，文件已放好。
  - 点“加入新版本…”照常可用。
  - 标题最多两行；“重命名”改成标题旁的文字按钮。
- **审阅人改名**：
  - 审阅稿、定稿和导出报告里的修订和批注，一律用设置里现在的姓名和缩写。以前，旧决定的批注还署改名前的名字。
  - 改名后，已有的审阅稿会自动重写一次。

## 测试

- 单元测试：比较引擎 41、模板 / 往来稿 4、文件名规则 5、审阅稿写入 77，全部通过。
- 端到端：审阅稿、模板、往来稿三套全部通过。
- beta.4 新增检查全部通过：
  - 文件名框可以删空；
  - 插入标签不加“-”；
  - 改名后审阅稿重写；
  - 拖文件到版本片会打开放置区；
  - 撤销提示保持一行。
- 性能：修订审阅里按 J 逐处切换，和 beta.3 交替各测 3 轮。
  - 中位数：beta.4 48–53 ms，beta.3 48–54 ms。
  - P95：beta.4 71–77 ms，beta.3 77–78 ms。
  - 没有差别。
