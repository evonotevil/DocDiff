# DocDiff 1.9.2

修复版。设置、审阅结论、往来稿和模板都原样保留。新的提示弹窗先在 Figma 里确认过（「方案 · 1.9.1」F10）。

## 快速审阅后立即离开，审阅稿不再漏写

以前在修订审阅里连续按 R / A / H 后马上退出、点「新建比较」或从版本链切到别的版本，最后一批决定会存进 DocDiff，但没写进 Word 审阅稿。现在：

- 离开比较页后，还没写进去的决定会在后台马上写完（不再等那 0.25 秒）。
- 同一份审阅稿的写入按先后排队；回到这一对文件又改了决定时，最后写进去的一定是最新决定，旧的不会盖掉新的。
- 还有决定没写进去时，审阅稿状态片显示“保存中”，不显示“已保存”，完成页和导出也不会把它当成可以发给对方的文件。
- 退出前先写完；Word 正开着审阅稿等原因写不完时，会问你「仍然退出 / 先不退出」。
- 写不进去时（Word 正在用、被改过、被移走、文件夹写不进），会弹窗写明哪份审阅稿、几个决定没写进去、为什么。这些决定都保存在 DocDiff 里；重启后会再提醒一次，再打开这次比较时自动补写。

## 往来稿：上一轮的结论不再丢

- 快速审阅后马上切到下一版，上一轮的结论摘要以前可能没存上，下一轮的「上轮」提示和条款历史就看不到。现在切版本、新建比较、退出时都会先存好，不管有没有生成 Word 审阅稿。

## 第一次审阅决定不再卡一下

- 打开提示音时，第一次按 R / A / H 会卡一下（Mac 上约 0.2–0.3 秒）。提示音改成另一种播放方式，声音不变，不再卡。关掉提示音时不做任何准备。
