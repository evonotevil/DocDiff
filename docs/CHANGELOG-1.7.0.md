# DocDiff 1.7.0

按《DocDiff 设计规范 3.0》重做结果页的骨架。比较引擎、导出、审阅逻辑和保存的数据都没有变，覆盖安装即可。

## 结果页：工具栏 + 侧栏 + 画布 + 检查器

- **工具栏**（高 56）放作用于整份比较的事：左边两个文件片和交换，中间上一处 / 下一处和“第 n / N 处”（审阅时换成进度条），右边比较设置、复制摘要、导出。导出是结果页唯一的绿色按钮；审阅时把绿色让给“接受”。
- **检查器**（原右栏）只做一件事：看差异。顶部一行筛选片（全部、删除、新增、修改、格式、移动、需要留意）同时就是概览计数；下面是按条款分组的差异清单，占满高度；底部一行“比较范围”，点“详情”看完整凭证。
- 原右栏的面板全部拿掉：差异概览变成筛选片，“需要留意”变成筛选片和行尾的 ⚠，“比较设置”收进工具栏齿轮的弹出层，“批量处理”收进审阅时检查器标题右侧的“…”菜单。
- **画布**：去掉了包在文档外面的卡片边框；顶部一行说明看的是什么，右边是这个模式的视图选项（只看有变化的段落、并排 / 合并、图像对比方式、OCR 语言等）。
- 三栏的区块标题都落在同一条线上（56 与 96）。

## 联动

- 悬停清单里的一行：纸上对应的字描边，差异地图上对应刻度变粗，不跳转。
- 点一行或点纸上的差异，两边互相跟随；工具栏显示“第 n / N 处”。
- 筛选片是唯一的筛选入口，清单、地图、上一处 / 下一处同时只看这一类。

## 侧栏与检查器的收起 / 展开

- 侧栏收起后变成 72 宽的图标栏，六个模式仍可切换；开关在侧栏标题行右端，快捷键 ⌃⌘S（Windows：Ctrl+Alt+S）。
- 检查器可完全隐藏；开关在工具栏最右端，快捷键 ⌥⌘I（Windows：Ctrl+Alt+I）。收起时上一处 / 下一处和审阅栏照常工作。
- 状态记在本机。窗口窄于 1180px 时侧栏默认收起，检查器以抽屉形式盖在画布上。
- 原来贴在画布边缘的圆形把手去掉了。

## 颜色

- 差异色全部换成多邻国原色：删除 Cardinal、新增 Mask、格式 Humpback、移动 Beetle。色弱模拟下最小差 12.7、正常视力最小差 24.4（1.6.2 为 8.5 / 20.2）。纸上用墨色 + 浅色高亮 + 线型，界面里只出现在 8px 圆点和 22px 编号圆上。
- 所有颜色、尺寸、圆角、时长都来自 `docs/design-tokens.json`，由 `npm run tokens` 写入样式表；`npm run tokens:check` 检查是否同步。
- 次要文字加深一级（#6f6f6f），在侧栏底色上达到 4.7:1。
- 比对报告 PDF 里的差异颜色同步换成新色。

## 字和标题

- 标题只有四级：页面 / 弹窗 22/900、区块 13/800、分组 12/800、行 15/700。区块标题和分组标题不再带图标。
- 按钮 15/800，三种高度 48 / 36 / 30；英文界面的按钮和区块标题全大写。
- 侧栏的模式图标改成 24px 彩色方块加白色线条。界面图标统一为 20px、2px 线。

## 用词

- “变更列表 / 差异概览”合并为“差异”；“修订列表”改为“修订”；“比较范围与条件”改为“比较范围”；“识别置信度”改为“识别质量”。
- 界面里不再出现“变更”“改动”，统一叫“差异”。
- 审阅完成页标题改为“全部看完了！”。

## 其他

- 审阅栏浮在纸面下方（圆角 18、带阴影），做出决定后整条变色；快捷键直接标在按钮上。
- 文件片点一下就能换文件，也可以直接把文件拖上去替换；文件在磁盘上被修改时右上角出现蓝点。
- 视图菜单新增“收起 / 展开侧栏”“收起 / 展开检查器”；设置里的快捷键表同步。
- Windows 标题栏按钮区高度改为 56，与工具栏对齐；macOS 红绿灯位置随之下移。
