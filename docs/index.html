不知道该选哪个版本？

Mac 点击左上角苹果菜单 →“关于本机”，查看芯片。如果显示 Apple M 系列，选 Apple 芯片；显示 Intel，选 Intel 芯片。Windows 选择 Windows 版。

首次安装和打开

目前 macOS 和 Windows 安装包尚未签名。请从本项目的发布页下载，并可用 SHA-256 校验文件确认下载完整。

macOS：打开 DMG，将 DocDiff 拖入“应用程序”。若系统提示无法验证开发者，先确认文件来自官方发布页，再到“系统设置 → 隐私与安全性”查看打开选项。Apple 官方说明 ↗

Windows：双击安装包。如出现 SmartScreen 提示，请先确认来源，再查看“更多信息”中的继续选项；若无法继续，可在 GitHub Issues 反馈。
