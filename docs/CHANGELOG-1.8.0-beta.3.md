# DocDiff 1.8 测试版 3（1.8.0-beta.3）

在 beta.2 的基础上，按试用反馈和确认过的设计稿修改界面，功能不变。

## 改了什么

- **最近比较**：改成两行。
  - 第一行：两份文件各带类型标签（DOCX / PDF），名字太长时省略中间、保留结尾，中间的 → 上下对齐。
  - 第二行：时间 · 进度条 · 已审 x / y，几行之间对齐。
  - 末尾仍是「…」菜单。
- **工具栏不再溢出**：
  - 窗口变窄时，按钮依次收成图标：复制摘要 → 导出 → 审阅稿（只留状态圆点）。
  - 往来稿的版本片最多占约三分之一宽，名字省略中间，悬停看全名。
  - 普通比较的两个文件片同样处理；更窄时去掉「原始 / 修改后」字样。
  - 计数（如 11 / 19）不会再换行。
- **「加入新版本」弹窗**：按弹窗规范重做。
  - 标题 22 号，控件高 48。
  - 选好文件后，放文件的区域变成一行文件名，右边是「更换」。
  - 「这一版是谁改的」下面写明为什么这样默认。
  - 主按钮写明要比较哪两版，如「加入并比较 V3 → V4」。
- **审阅稿首次提示**：文件名单独成一行，不再夹在句子里折行。
- **「生成定稿」弹窗**：「将生成」改成和上面一样的文件行，并写明命名规则在哪里改。
- **文件名规则**（设置 · 审阅）：
  - 改成标签加文字：日期 / 对方文件名 / 版本号 / 审阅人，标签之间可以直接打字，如 `日期-对方文件名-legal`。
  - 点日期标签可以切换 20261030 和 2026-10-30 两种格式。
  - 下方实时预览文件名。
  - 版本号只在往来稿里有值；没有值时，连同旁边的「-」一起省掉。
  - 旧设置（如 `{name}-定稿`）照常可用。
- **弹窗规范**：所有弹窗标题统一为 22 号。「用模板比较」「加入新版本」「生成定稿」的间距和按钮按规范调整。

## 测试

- 单元测试：比较引擎 41 项、模板 / 往来稿 4 项、文件名规则 5 项、审阅稿写入 77 项，全部通过。
- 端到端：审阅稿、模板、往来稿三套全部通过。
- 性能：修订审阅里按 J 逐处切换（约 100 页的 Word），和 beta.2 交替各测 3 轮。
  - 中位数：beta.3 51–53 ms，beta.2 52–55 ms。
  - P95：beta.3 74–76 ms，beta.2 72–83 ms。
  - 两者没有差别。
