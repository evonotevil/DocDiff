# 1.9.9 方案（已实施，见 CHANGELOG-1.9.9.md）

对应 ISSUES-1.9.md 第 7–10 条。Figma：「方案 · 1.9.9 · 使用反馈（待确认）」页。

## 1. 侧栏顶部：两个平台都显示字标，去掉「比较模式」（ISSUES 7）

- 现状：Mac 侧栏头部不画字标；两个平台都有「比较模式」小标题。
- 用户选定：Mac 上红绿灯那一行只留右侧的收起按钮，字标放在下一行；Windows 字标和收起按钮仍在同一行。两个平台都删掉「比较模式」小标题（导航的读屏名称保留）。
- 待在 Figma 定的细节：Mac 字标那一行的高度和上下间距，保证模式列表的起点和 Windows 接近。

## 2. 首页顶栏：字标和内容左边对齐（ISSUES 8，选 A）

- 用户选定：字标的左边缘和下面模块的左边缘对齐，两个平台同一套规则；窗口窄到内容左边缘落进红绿灯区时，Mac 上退回红绿灯右侧（92px）。顶栏高度不变。
- 已在 Figma 画好（U2，已选 A）。

## 3. 示例合同补上 1.9.x 的功能（ISSUES 9）

- 用户选定，四样都补：
  - 批注：对方稿加 2–3 条对方批注，其中一条带我方回复（我方作者用设置里的默认审阅人能认出的名字，比如“法务”）。
  - 批注所在段被去掉：一条批注落在对方删掉的段落上，拒绝后出现占位行。
  - 图片变化：两版各一张小示意图，有一处不同。
  - 移动和格式：一条条款换位置；一处加粗或字号修改。
- 内容继续虚构（星河科技 × 北辰数据）；核对 `Demo.tsx` 里引用的示例文字。

## 4. 文件名规则编辑器（ISSUES 10）

- 用户选定：
  - 标签拖动排序，落点显示插入线；选中标签后 Alt+← / → 移动。
  - 「插入」区的按钮可以拖进框里；点一下仍插在光标处。
  - 文字框按实际字宽贴合。
- 存储格式不变（`{date}-{name}` 这类文本规则），旧设置兼容。
- 待在 Figma 定的细节：拖起的标签、插入线、拖动中的输入框样式。
