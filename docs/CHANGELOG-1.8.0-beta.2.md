# DocDiff 1.8 测试版 2（1.8.0-beta.2）

在 beta.1 的基础上，按试用反馈修改。功能说明见 `更新说明-1.8.0-beta.1.md`。

## 改了什么

- **首页**：「往来稿」和「模板」改成两张卡片，按设计稿用一行一条的紧凑行。「最近比较」放进往来稿卡片里作为一组。两份文件名太长时保留开头和结尾。
- **「存为往来稿」**：从悬停按钮改到每行末尾的「…」菜单里，不再压住文件名。「从列表移除」也在这个菜单里。
- **拖放**：「用模板比较」和「加入新版本」两个弹窗都能直接把文件拖进去。
- **「加入新版本」弹窗**：按设计规范重做。
  - 上面是放文件的区域；
  - 「这一版是」改成分段按钮（对方发来的 / 我方改的）；
  - 「和哪一版比较」从下拉框改成版本列表，默认选上一版。
- **审阅稿第一次保存时说明一次**：「你做的每个决定都已经写进 xx-我方意见.docx，不用再导出；要发给对方的就是这份。」点「知道了」以后不再出现。
- **「生成定稿」简化**：
  - 只说明一句：定稿是一份干净的 Word，没有修订标记，也没有批注。
  - 还有没决定的处时，只问一个问题：「用对方的改动 / 改回我方原文」。
  - 去掉了「保留批注」开关。
- **文件名**：对方文件本身是「…-定稿」「…-我方意见」时，不再生成「-定稿-定稿」这样的重复后缀。往来稿的默认名字也一样处理。
- **设置**：每个选项的上下留出间距，分隔线不再贴着文字。「审阅」页的图标改成和其他页一样的单色。审阅人说明改成和审阅稿一致的说法。
- **格式差异的文字**：「突出显示 #FFFF00」改成「突出显示 黄色」，颜色变化也显示颜色名。
