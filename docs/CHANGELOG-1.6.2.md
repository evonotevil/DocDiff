# DocDiff 1.6.2

这一版按新的《DocDiff 设计语言 v2.0》重做了外观：外壳找回 1.5.1 的多邻国颜色和手感，文档部分保持清楚克制。比较、导出和审阅的功能没有变化。

## 颜色和手感回来了

- 品牌色恢复多邻国原色（绿 #58cc02、蓝 #1cb0f6、红 #ff4b4b、黄 #ffc800），中性灰也换回多邻国的灰。
- 所有按钮、概览格、最近比较卡片、放好文件的放置区，都有 2px 边框和 4px 立体底边，按下会下沉。
- 标题字重回到 900，按钮和标签 800；圆角加大。
- 文件类型徽标恢复彩色（DOCX 蓝、PDF 红）；首页“选择文件”改回蓝色实心按钮。
- “开始比较”在文档没到齐时显示为浅绿按钮，旁边写“还差 N 个文档”。

## 首页

- 吉祥物“对对”旁边加了一句话，会随着放入文档的情况变化。
- 标题下方用彩色图标列出五种比较模式。
- 拖文件进来时，整块放置区变成蓝色。
- 最近比较卡片显示审阅进度条，审完的显示“已审完”。

## 每个模式有自己的颜色

左栏六个模式选中时用各自的颜色：富文本蓝、纯文本灰、修订审阅黄、图像绿、OCR 紫、文件详情橙。

## 差异色换成多邻国色系

- 删除珊瑚红、新增薄荷绿、格式皇家蓝、移动兰花紫，重新通过色弱校验（色弱最小差 8.5，正常视力最小差 20.2）。
- 每种差异有亮面、底边、墨色、浅底四个色阶：亮面用在色块和圆点上，文档里的文字用深色墨，保证清楚。
- 修改仍是红绿双色。
- 比对报告 PDF 同步换成新颜色。

## 右栏

- 白底，面板 2px 边框，标题 900 字重；“需要留意”是黄色面板。
- 差异概览改成两列三行的彩色图标块，第一格“全部”用来清除筛选。
- 变更列表恢复彩色编号圆点；审阅过的圆点变成 ✓ 或 ✕。当前这一处用蓝色选中态。
- 面板高度重新分配：概览和批量处理不再被压缩，变更列表至少留出 240px；“批量处理”默认收起。
- 1.6.1 的折叠、“只看这一块”、记住展开状态都保留。

## 交互反馈

- 做出决定后，审阅栏整条变色，结论弹出，列表里的圆点变成 ✓ / ✕。
- 审到一半时提示“过半了！还剩 N 处”。
- 完成页“对对”欢呼，配彩色统计卡。
- 空状态都有“对对”：比较中思考、出错时尴尬、等待识别时犯困、没有修订时欢呼。
- 系统开启“减少动态效果”时，动画全部关闭。

## 文档

- 新增 `docs/design-language.html`：完整的设计语言，带可操作的组件样板和界面示意。
- `docs/design-standard.md` 更新为设计语言 v2.0 的文字版。
